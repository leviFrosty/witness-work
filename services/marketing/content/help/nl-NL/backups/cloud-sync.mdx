title: Wat is Cloud Sync?
---

Cloud Sync houdt je gegevens op al je apparaten gelijk: iPhone, Android en het web. Het werkt tussen een iPhone en een Android-telefoon, en het is gratis. Alleen jij kunt je gegevens lezen.

Een nieuwe installatie begint met Cloud Sync aan. Zie [Staat Cloud Sync standaard aan?](/help/backups/cloud-sync-default).

## Je synchronisatie bekijken of wijzigen

1. Open **Instellingen → Synchroniseer**.
2. Bekijk welke optie dit apparaat gebruikt, of kies Cloud Sync, iCloud (Google Drive op Android) of Uit.

## Goed om te weten

- Je apparaten synchroniseren alleen met apparaten die dezelfde optie gebruiken, dus kies op elk dezelfde. Wijzigingen komen meestal binnen enkele seconden aan zolang de app open is.
- Je profielfoto, contactfoto's en foto's in notities worden ook gesynchroniseerd. Zie [Worden foto's gesynchroniseerd met Cloud Sync?](/help/backups/cloud-sync-photos).
- Het web werkt alleen met Cloud Sync. Gebruikt je telefoon iets anders, dan vraagt het web om het aan te zetten. Zie [Waarom is mijn telefoon overgestapt op Cloud Sync?](/help/backups/cloud-sync-from-web).
- Een nieuwe telefoon die je instelt met de QR-code of herstelsleutel van je account, krijgt je gegevens via Cloud Sync. Je hoeft niet te herstellen.
- Is je nieuwste back-up nieuwer dan je Cloud Sync-kopieën, dan biedt de nieuwe telefoon ook aan die te herstellen.
- Werk WitnessWork bij als het vraagt om Supporter-toegang om Cloud Sync te gebruiken.

## Als er iets misgaat

- **Bij Instellingen → Synchroniseer staat dat Cloud Sync is gepauzeerd of nog niet beschikbaar is:** je wijzigingen blijven op dit apparaat en worden gesynchroniseerd zodra het weer werkt. Tik op **Nu synchroniseren** om opnieuw te kijken.
