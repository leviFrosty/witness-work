id: cloudSync
title: Что такое Cloud Sync?
---

Cloud Sync делает ваши записи одинаковыми на всех устройствах: iPhone, Android и в веб-версии. Он работает между iPhone и телефоном Android и бесплатный. Прочитать записи можете только вы.

После новой установки Cloud Sync включён. См. [Включён ли Cloud Sync по умолчанию?](/help/backups/cloud-sync-default)

## Посмотрите или измените синхронизацию

1. Откройте **Настройки → Синхронизация устройств**.
2. Посмотрите, какой вариант использует это устройство, или выберите Cloud Sync, iCloud (на Android — Google Drive) или «Выключено».

## Полезно знать

- Ваши устройства синхронизируются только с устройствами на том же варианте, поэтому выберите один и тот же на каждом. Изменения обычно приходят за несколько секунд, пока приложение открыто.
- Фото вашего профиля, фото контактов и фото в заметках тоже синхронизируются. См. [Синхронизируются ли фото через Cloud Sync?](/help/backups/cloud-sync-photos)
- Веб-версия работает только с Cloud Sync. Если ваш телефон использует другой вариант, веб-версия предложит включить его. См. [Почему мой телефон перешёл на Cloud Sync?](/help/backups/cloud-sync-from-web)
- Новый телефон, который вы настроили с помощью QR-кода аккаунта или ключа восстановления, получает ваши записи через Cloud Sync. Восстанавливать ничего не нужно.
- Если ваша последняя резервная копия новее копий в Cloud Sync, новый телефон предложит восстановить и её.
- Обновите WitnessWork, если он просит доступ для сторонников, чтобы использовать Cloud Sync.

## Если что-то пошло не так

- **В Настройки → Синхронизация устройств написано, что Cloud Sync приостановлен или ещё недоступен:** ваши изменения остаются на этом устройстве и синхронизируются, когда он заработает. Нажмите **Синхронизация**, чтобы проверить снова.
