title: Pourquoi ne puis-je pas scanner le code QR de la carte, ou pourquoi mon lien de carte ne fonctionne-t-il pas ?
---

Regardez le message affiché ci-dessous. Si le code de la carte ne se scanne pas, vous pouvez saisir le lien ou utiliser une autre option de carte.

## Scanner le code QR de la carte

Cela n’existe que dans les applications pour téléphone. Sur le web, collez le lien avec **Saisir le lien de la carte**.

- **« WitnessWork a besoin de l’appareil photo pour scanner un code QR. »** Touchez **Ouvrir les réglages**, autorisez l’appareil photo pour WitnessWork, puis réessayez.
- **« Ce code QR ne contient pas de lien web. »** Le code contient autre chose qu’une adresse web. Utilisez **Repère sur une carte** ou **Tracer le contour de la zone**, ou prenez la carte en photo.
- **Rien ne se passe :** tenez la carte bien à plat et immobile, avec une bonne lumière, le code entier dans le cadre. Touchez **Arrêter le scan** pour saisir le lien à la place.

## Un lien de carte qui ne fonctionne pas

**Saisir le lien de la carte** enregistre n’importe quel lien que vous collez. Ouvrez-le avec le bouton **Carte** du territoire.

WitnessWork essaie aussi de placer un repère pour **Directions**. Cela fonctionne avec les liens vers un lieu dans Google Maps, Plans d’Apple ou OpenStreetMap. Un lien court, comme maps.app.goo.gl, demande une connexion pendant que « Recherche de l’emplacement… » s’affiche.

Si aucun repère n’apparaît, le lien s’ouvre quand même. Touchez **Repère sur une carte** et touchez l’endroit du territoire. Un repère que vous avez placé vous-même n’est pas déplacé par un lien.

## Scanner des notes

Sur iPhone et iPad, « Aucun texte n’a été trouvé dans le scan » signifie qu’il faut scanner de nouveau avec une meilleure lumière et la page à plat, ou saisir les notes. Sur Android, copiez le texte d’une photo avec Google Lens, puis collez-le.
