Cloud Sync keeps your records the same on all your devices: iPhone, Android and the web. It works between an iPhone and an Android phone, and it's free. Only you can read your records.

A new install starts with Cloud Sync on. See [Is Cloud Sync on by default?](/help/backups/cloud-sync-default).

## See or change your sync

1. Open **Settings → Sync**.
2. See which option this device uses, or choose Cloud Sync, iCloud (Google Drive on Android), or Off.

## Good to know

- Your devices sync only with devices on the same option, so choose the same one on each. Changes usually arrive within seconds while the app is open.
- Your profile photo, contact photos and photos in notes sync too. See [Do photos sync with Cloud Sync?](/help/backups/cloud-sync-photos).
- The web works only with Cloud Sync. If your phone uses something else, the web asks to turn it on. See [Why did my phone switch to Cloud Sync?](/help/backups/cloud-sync-from-web).
- A new phone you set up with your account's QR code or recovery key gets your records through Cloud Sync. You don't need to restore.
- If your newest backup is newer than your Cloud Sync copies, the new phone offers to restore it too.
- Update WitnessWork if it asks for Supporter access to use Cloud Sync.

## If something goes wrong

- **Settings → Sync says Cloud Sync is paused or not available yet:** your changes stay on this device and sync when it's back. Tap **Sync now** to check again.
