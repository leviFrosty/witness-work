---
id: cloudSyncFromWeb
title: Pourquoi mon téléphone est-il passé à Cloud Sync après ma connexion sur le web ?
---

Quand vous vous connectez sur le web, on vous demande d’activer [Cloud Sync](/help/backups/cloud-sync), car le web ne fonctionne qu’avec Cloud Sync. Si vous choisissez **Activer**, votre téléphone passe à Cloud Sync la prochaine fois que vous y ouvrez WitnessWork.

## Rien n’est perdu

- Votre téléphone garde chaque enregistrement et chaque photo, et les combine avec ce qui se trouve déjà dans Cloud Sync.
- Rien de ce que vous avez supprimé ne revient.
- Vos autres téléphones du même compte passent aussi à Cloud Sync, chacun la prochaine fois que vous y ouvrez WitnessWork.
- Vos enregistrements sont privés. Seuls vos propres appareils peuvent les lire.

## Revenir en arrière

1. Sur votre téléphone, ouvrez **Paramètres → Synchronisation**.
2. Choisissez iCloud (Google Drive sur Android) ou Désactivée.

Votre téléphone reste sur l’option que vous choisissez. Le web vous le redemandera la prochaine fois que vous l’utiliserez.

## S’il ne change pas

- Vérifiez que votre téléphone est en ligne et que vous avez terminé la configuration de WitnessWork, puis ouvrez de nouveau l’application.
- Si le web affiche **Mettez WitnessWork à jour sur votre téléphone**, mettez l’application à jour depuis l’App Store ou Google Play, puis ouvrez-la.
- Vous pouvez toujours choisir Cloud Sync vous-même dans **Paramètres → Synchronisation**.
