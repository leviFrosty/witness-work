---
id: importOtherApps
title: Kann ich Daten aus MyTime, Ministry Assistant oder einer anderen App importieren?
---

Sie können eine MyTime-Sicherung importieren. Dateien anderer Apps werden nicht unterstützt, aber Sie können lesbaren Text in Scribe AI einfügen.

## Aus MyTime importieren

1. Gehen Sie in MyTime zu **More → Settings → Backup** und senden Sie sich selbst eine Sicherung per E-Mail.
2. Speichern Sie die angehängte .mytimedb-Datei auf Ihrem Gerät. Auf Android oder im Web senden Sie sie von MyTime auf Ihrem iPhone und laden den Anhang auf diesem Gerät herunter.
3. Öffnen Sie in WitnessWork **Einstellungen → Daten importieren → Von MyTime**. Wählen Sie bei der Einrichtung stattdessen **Von MyTime**.
4. Wählen Sie die Datei.
5. Sehen Sie sich die Vorschau an und importieren Sie dann.

## Gut zu wissen

- Im Web bleibt die Datei in Ihrem Browser und wird nicht hochgeladen. Eine Datei über 25 MB wird abgelehnt.
- Bei einer anderen App versuchen Sie, lesbaren Text zu exportieren und in Scribe AI einzufügen. Prüfen Sie, was es vorschlägt, bevor Sie speichern.
- WitnessWork-Sicherungsdateien gehören nach **Einstellungen → Sichern und Wiederherstellen**, nicht hierher.
- Um später Daten aus Notizen oder von Papier zu übernehmen, nutzen Sie **Einstellungen → Daten importieren**.

## Wenn es heißt, die Datei sei keine Datenbank

Für den Import brauchen Sie die originale .mytimedb-Datei, die MyTime erstellt hat. Ein PDF, ein Text-Export, eine WitnessWork-Sicherung oder eine umbenannte Datei funktionieren nicht. Behalten Sie die Originaldatei unverändert. Wenn eine gültige Sicherung trotzdem fehlschlägt, schreiben Sie dem Support privat eine E-Mail mit dem Fehler und Ihrer WitnessWork-Version. Veröffentlichen Sie die Sicherung nicht.
