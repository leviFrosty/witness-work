title: ¿Por qué no se abre un enlace de invitado o un código QR de un territorio, o por qué dice que terminó o caducó?
---

La página dice qué pasa. Un enlace funciona hasta que se acaba su tiempo o hasta que lo termina la persona que lo compartió.

## Qué dice la página

- **"Este enlace ha caducado":** se acabó el tiempo del enlace. Pide uno nuevo si todavía estás trabajando.
- **"Este enlace ha terminado":** quien lo compartió lo terminó, devolvió el territorio o recuperó la calle. Pide un enlace nuevo.
- **"Este enlace no funciona":** falta una parte del enlace. A veces las apps de mensajes cortan los enlaces largos. Copia el enlace completo, o escanea el código QR.
- **"Sin conexión":** conéctate a internet para abrir el enlace. Cuando se abre, lo que registres sin conexión se envía cuando vuelvas a tenerla.
- **"Enlaces en pausa":** inténtalo de nuevo en unos minutos.
- **"Ninguna de las calles de este enlace se puede registrar ahora":** las calles se transfirieron o se recuperaron. Pregunta a quien compartió el enlace.
- **"1 cambio no se guardó. Esa calle ya no está compartida con este enlace."** o **"los registros de este navegador no se guardaron":** el enlace terminó antes de que tu teléfono pudiera enviarlos. Dile a quien compartió el enlace lo que registraste.

## Es bueno saber

- Escanea el código QR con la cámara de tu teléfono y toca el enlace que aparece.
- Tu navegador conserva los registros del enlace hasta que termine. Toca **Olvidar este enlace** para borrarlos antes. Los registros ya enviados se quedan con el grupo.

## Si compartiste el enlace

Abre el territorio y mira en **Compartido con**. Un enlace que terminó o caducó muestra cuándo. Para crear uno nuevo, toca **Compartir** y luego **Un enlace o código QR**. Consulta [¿Cómo comparto un territorio con alguien que no tiene la app?](/help/territories/territories-guest-link)
