---
id: logTimeReminders
title: Kann WitnessWork mich erinnern, Zeit für einen geplanten Tag zu erfassen?
---

Ja. Wenn ein Tag einen Plan hat, aber keine Zeit erfasst ist, sendet WitnessWork abends eine Erinnerung.

## Einschalten

1. Öffnen Sie **Einstellungen → Benachrichtigungen**.
2. Schalten Sie **Erinnerung ans Erfassen der Zeit** ein.
3. Wählen Sie eine Zeit unter **Erinnern um**. Das sind 20:00 Uhr, wenn Sie es nicht ändern.
4. Erlauben Sie Benachrichtigungen, wenn WitnessWork danach fragt.

Wenn Sie diese Einstellung erst sehen, nachdem Sie **Meine Stunden erfassen** eingeschaltet haben, ist das normal: Sie erscheint, wenn Sie Stunden erfassen.

## Gut zu wissen

- Die Erinnerung kommt, nachdem die Pläne des Tages enden. Ein Plan, der zu Ihrer Erinnerungszeit noch läuft, erinnert Sie am nächsten Tag.
- Mehrere Pläne an einem Tag ergeben eine Erinnerung.
- Tippen Sie auf die Erinnerung, um **Zeit hinzufügen** mit Datum, geplanter Zeit und Typ bereits ausgefüllt zu öffnen.
- Wenn Sie für diesen Tag irgendeine Zeit erfassen, wird die Erinnerung abgebrochen. Das Löschen der Pläne oder das Ausschalten der Einstellung tut das auch.
- Für Tage, die Sie verpasst haben, bevor Sie dies eingeschaltet haben, und für Pläne ohne festgelegte Zeit gibt es keine Erinnerungen.
- Die Erinnerung wird eine Woche lang auch in der Glocke auf dem Startbildschirm angezeigt.
- Erinnerungen werden auf Ihrem Smartphone aus Ihren eigenen Plänen erstellt. Es wird nichts irgendwohin gesendet.
- Öffnen Sie WitnessWork mindestens alle zwei Wochen, damit die Erinnerungen weiter kommen.

## Wenn etwas schiefgeht

- **Es kommen keine Erinnerungen:** Achten Sie darauf, dass Benachrichtigungen für WitnessWork in den Einstellungen Ihres Smartphones erlaubt sind und dass „Fokus“ oder „Nicht stören“ aus ist. Auf Android prüfen Sie auch die Kategorie „Erinnerungen“.
- **Eine Erinnerung kam, nachdem Sie Zeit auf einem anderen Gerät erfasst haben:** Öffnen Sie WitnessWork auf diesem Smartphone, damit sie abgebrochen werden kann.
- **Android kommt ein paar Minuten zu spät:** Das System verzögert Erinnerungen möglicherweise, um Akku zu sparen.
