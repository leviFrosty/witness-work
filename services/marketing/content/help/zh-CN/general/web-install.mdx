title: 怎样把 WitnessWork 安装到主屏幕或桌面？
---

你可以在浏览器标签页中使用 WitnessWork，也可以安装它，让它像应用一样在自己的窗口中打开。两种方式用的都是同一个应用。

## 安装

- **电脑上的 Chrome 或 Edge：** 打开 app.witnesswork.app，使用地址栏中的安装图标，或者菜单中的**安装**项。
- **Mac 上的 Safari：** 打开**文件**菜单，选择**添加到程序坞**。
- **iPhone 或 iPad：** 在 Safari 中，点按**分享**，然后点按**添加到主屏幕**。
- **Android：** 在 Chrome 中，点按顶部**安装应用**横幅上的**安装**，然后确认。或者使用浏览器的菜单，选择**安装应用**或**添加到主屏幕**。

## 好知道

- iPhone 主屏幕上的网页应用，即使你有一段时间没有打开，也会保留它的数据。请参阅[WitnessWork 在我的浏览器中保存了什么？](/help/general/web-storage)。
- 在 iPhone 和 iPad 上，Safari 会改为显示 Apple 的 App Store 应用横幅。
- 点按 X 可以关闭**安装应用**横幅。在那个浏览器中，它会一直保持关闭，直到该网站的数据被清除，或者你退出登录。
- 在电脑上，或者在 WitnessWork 已经安装之后，不会显示横幅。
