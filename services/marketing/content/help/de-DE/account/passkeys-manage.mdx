title: Wie unterscheide ich meine Passkeys, und wie entferne ich einen?
---

Jeder WitnessWork-Passkey heißt „WitnessWork“ mit einem Code aus 4 Zeichen, zum Beispiel WitnessWork 7K4Q. Derselbe Code steht unter **Einstellungen → Konto → Passkeys**, sodass Sie sie zuordnen können.

## Ihre Passkeys ansehen

Öffnen Sie **Einstellungen → Konto → Passkeys**. Sie listet jeden Passkey mit dem Gerät, auf dem er hinzugefügt wurde, dem Zeitpunkt des Hinzufügens und der letzten Nutzung. Jeder ist markiert:

- **Kann Ihr Konto entsperren:** Die Anmeldung damit bringt Ihr Konto in einen neuen Browser oder auf ein neues Smartphone.
- **Nur zum Anmelden:** Er meldet Sie an und bittet Sie dann, mit Ihrem anderen Smartphone oder Ihrem Wiederherstellungsschlüssel abzuschließen. Danach kann er beim nächsten Mal vielleicht entsperren.

Tippen Sie auf einem Smartphone auf einen Passkey **Nur zum Anmelden** und wählen Sie **Entsperren erlauben**, um es noch einmal zu versuchen. Manche Passwortmanager können nur anmelden.

## Einen Passkey entfernen

1. Öffnen Sie **Einstellungen → Konto → Passkeys**.
2. Tippen Sie auf den Passkey.
3. Wählen Sie **Entfernen**.
4. Bestätigen Sie mit Face ID, Ihrem Fingerabdruck oder Ihrem Code. Im Web bestätigen Sie stattdessen mit einem Ihrer Passkeys.

## Gut zu wissen

- Das Entfernen hier löscht ihn nicht aus Ihrem Passwortmanager. Löschen Sie ihn auch dort.
- WitnessWork warnt Sie, bevor Sie den letzten Passkey entfernen, der Ihr Konto entsperren kann.
- Sie können einen Passkey nicht umbenennen.
- Wenn die Glocke auf dem Startbildschirm sagt, ein Passkey wurde hinzugefügt, und das waren nicht Sie, entfernen Sie ihn und ändern Sie Ihren Kontoschlüssel. Siehe [Was tue ich, wenn mein Smartphone oder Computer verloren geht oder gestohlen wird?](/help/account/lost-device).
- Bevor Sie Ihren einzigen Weg hinein entfernen, prüfen Sie, ob Sie Ihren Wiederherstellungsschlüssel haben. Siehe [Was ist mein Wiederherstellungsschlüssel, und wie bewahre ich ihn sicher auf?](/help/account/account-recovery-key).
