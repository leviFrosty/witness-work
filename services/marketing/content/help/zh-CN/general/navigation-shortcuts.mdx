title: 在 iPad 上如何使用键盘快捷键导航？
---

将实体键盘连接到运行 iPadOS 26 或更高版本的 iPad，然后在主导航可见时按住 Command 键。底部标签页或侧边栏项目旁会出现小的快捷键标签。按下 Command 键和显示的数字即可打开对应的屏幕；松开 Command 键标签就会隐藏。数字按可见导航的顺序排列，所以默认情况下主页是 Command 1，联系人是 Command 2。其他数字取决于哪些项目可见，包括侧边栏中的设置。使用这些导航快捷键之前，请先关闭任何已打开的表单或其他屏幕；它们不会保存或放弃记录。系统只会统计快捷键的使用情况，不会统计你输入的内容。此功能需要安装了键盘功能的应用版本，在 iPhone 和 Android 上不可用。如果没有显示标签，请检查键盘是否已连接，返回主导航，并更新后重新打开应用。你随时都可以改用点按导航项目。如有其他问题，请使用帮助中心的私密支持链接，并且不要在公开的报告中附上联系方式。
