---
id: accountHandoffTrouble
title: Was ist, wenn die Anmeldung mit einem QR-Code nicht funktioniert?
---

Erstellen Sie auf Ihrem alten Smartphone einen neuen Code und scannen Sie ihn erneut. Jeder Code funktioniert einmal und gilt 10 Minuten.

## Das probieren Sie

1. Tippen Sie auf dem alten Smartphone auf **Neuen Code erstellen**.
2. Prüfen Sie, ob beide Smartphones online sind.
3. Scannen Sie den neuen Code mit dem neuen Smartphone.
4. Prüfen Sie, ob beide Smartphones denselben sechsstelligen Code zeigen, und tippen Sie dann auf dem alten Smartphone auf **Erlauben**.

## Wenn etwas schiefgeht

- **Die Codes stimmen nicht überein:** Tippen Sie auf **Nicht erlauben** und fangen Sie von vorn an. Vielleicht hat jemand anderes Ihren Code gescannt.
- **Die Verbindung brach ab, nachdem Sie auf JA getippt haben:** Lassen Sie beide Smartphones auf dem Bildschirm. Das neue Smartphone zeigt **Erneut versuchen** und macht von selbst weiter, sobald es wieder online ist.
- **Das alte Smartphone sagt, Ihr Konto sei nicht gesendet worden:** Prüfen Sie seine Verbindung und tippen Sie erneut auf **Erlauben**.
- **Das neue Smartphone kann nicht scannen:** Erlauben Sie in den Einstellungen Ihres Smartphones, dass WitnessWork die Kamera nutzt.
- **Das neue Smartphone kann sich nicht verifizieren:** Installieren Sie WitnessWork aus dem App Store oder von Google Play. Siehe [Warum sagt WitnessWork, es könne dieses Gerät nicht verifizieren?](/help/account/account-verification).
- **Sie haben Ihr altes Smartphone nicht mehr:** Gehen Sie auf dem neuen Smartphone zu **Einstellungen → Konto → Wiederherstellungsschlüssel verwenden**. Siehe [Was ist, wenn ich den Zugang zu meinem WitnessWork-Konto verliere?](/help/account/lost-access).

Es klappt immer noch nicht? Wenden Sie sich über das Hilfezentrum an den Support. Senden Sie Ihren Wiederherstellungsschlüssel nie an jemanden.
