---
id: cloudSyncDefault
title: Cloud Sync est-il activé par défaut ?
---

Oui. Une nouvelle installation de WitnessWork démarre avec Cloud Sync activé, et vos enregistrements et vos photos se synchronisent entre vos appareils. Vous seul pouvez les lire.

## Garder vos enregistrements sur un seul appareil

1. Pendant la configuration, repérez l’étape Cloud Sync.
2. Désactivez le commutateur **Cloud Sync**.

Rien ne se synchronise, et vous pourrez l’activer plus tard dans **Paramètres → Synchronisation**.

## Si vous utilisiez déjà WitnessWork

Votre réglage ne change pas. Un message dans vos notifications, la cloche de l’Accueil, peut proposer **Activer** ou **Activer Cloud Sync**. Touchez-le pour changer, ou ignorez-le. Il ne reviendra pas.

- Si vous synchronisez avec iCloud (Google Drive sur Android), cela reste ainsi jusqu’à ce que vous le changiez.
- Si vous aviez désactivé la synchronisation, elle reste désactivée.

## Bon à savoir

- Pour le changer sur n’importe quel appareil, ouvrez **Paramètres → Synchronisation** et choisissez Cloud Sync, iCloud (Google Drive sur Android) ou Désactivée.
- Vos appareils ne se synchronisent qu’avec les appareils qui utilisent la même option. Choisissez donc la même sur chacun.
- WitnessWork sur le web n’utilise que Cloud Sync.
- Changer de mode ne remplace jamais d’enregistrements, et rien de ce que vous avez supprimé ne revient.
