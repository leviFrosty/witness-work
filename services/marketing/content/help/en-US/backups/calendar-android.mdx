title: How does Calendar Sync work on Android?
category: backups
platforms:
  - android
---

Calendar Sync is free on Android. During first-time setup, from the invitation in the notifications tray, or in Settings → Preferences → Calendar Sync, tap Add to Calendar or Choose a calendar, then allow calendar access. Create a WitnessWork calendar on this device, or choose an existing calendar used only for WitnessWork, such as one you created in Google Calendar and set to sync to this phone. A calendar created on the device stays on this device; a Google calendar also shows on your other devices and on the web. Main calendars can't be selected. Every upcoming Follow-up is then added as a 30-minute event with the same alert as its Notify Me reminder; Calendar Sync adds all of your upcoming Follow-ups or none. Past Follow-ups and Plans aren't added. Updates run when you open WitnessWork and after you save changes, and Sync now updates right away. Each event's description holds a WitnessWork link that identifies its Follow-up, so an update changes the existing event instead of adding another, even when another Android device updates the same Google calendar. Don't edit that link. An event you delete in your calendar app comes back on the next update. Android has no primary device and doesn't use iCloud, and Include names and addresses applies to this device only. If updates stop, for example because calendar access was turned off, a Calendar updates paused notification appears in the notifications tray; tap it for the fix, or open Calendar Sync to read the error. For calendar access, tap Open Settings, then Permissions → Calendar → Allow; setup or updates continue when you come back to WitnessWork. For other errors, tap Try Again. Turn Off Calendar Sync keeps or removes WitnessWork events; it never deletes the calendar or your other events. Uninstalling WitnessWork leaves its events, so remove them first if you don't want them. If the problem continues, use the private support option under Still need help? in the Help Center, and keep contact details and calendar screenshots out of public reports.
