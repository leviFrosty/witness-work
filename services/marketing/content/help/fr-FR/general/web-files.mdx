id: webFiles
title: Comment fonctionnent les photos, les exports et les sauvegardes sur le web ?
---

Sur le web, les téléchargements vont dans le dossier de téléchargements de votre navigateur. Les photos dans les notes fonctionnent, pas encore les photos de profil et de contacts.

## Photos

- **Photos dans les notes :** ajoutez-en une avec le bouton photo de l’éditeur de notes, en collant une image que vous avez copiée, ou en faisant glisser un fichier image sur la note. Elles se synchronisent avec vos téléphones par Cloud Sync. Les photos de notes de vos téléphones apparaissent une fois téléchargées ; d’ici là, la note indique « Cette photo n’est pas sur cet appareil. »
- Votre navigateur garde sa propre copie de chaque photo, et se déconnecter la supprime. Si le navigateur manque de place pour elles, WitnessWork vous le dit.
- **Photos de profil et de contacts :** vous ne pouvez pas encore en ajouter sur le web, et celles de vos téléphones n’y apparaissent pas. Les contacts affichent leurs initiales.
- Modifier un contact sur le web ne touche pas sa photo sur vos téléphones. Retirer ou remplacer la photo d’un contact ou votre photo de profil sur le web la retire bien de vos téléphones.

## Téléchargements et partage

- **Créer une sauvegarde**, **Exporter en CSV** pour un rapport de kilométrage et les autres exports se téléchargent sous forme de fichiers. Votre navigateur peut demander où les enregistrer, ou les lister dans ses téléchargements.
- Sur un ordinateur, **Partager le rapport** et les autres partages de texte copient le texte. Vous voyez « Copié ! » et pouvez le coller où vous voulez.
- Sur un téléphone, le partage ouvre la feuille de partage du téléphone. Si votre navigateur ne peut pas le faire, le fichier se télécharge.

## Imports

**Restaurer depuis une sauvegarde**, **Importer un contact** et l’import MyTime ouvrent le sélecteur de fichiers de votre navigateur. Les fichiers MyTime (.mytimedb) restent sur votre ordinateur, et un fichier de plus de 25 Mo est refusé. Les sauvegardes WitnessWork sont verrouillées par un mot de passe. Saisissez-le pour restaurer.

## Bon à savoir

- Une sauvegarde téléchargée peut contenir des informations sur les personnes que vous visitez. Gardez-la privée.

## En cas de problème

- **Rien ne se télécharge :** vérifiez que votre navigateur ne bloque pas les téléchargements pour ce site. Pour plus d’aide, voir [Contacter l’assistance](/help).
