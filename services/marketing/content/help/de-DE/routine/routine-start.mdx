title: Was ist die Geistige Routine, und wie richte ich sie ein?
---

Die Geistige Routine hilft Ihnen, neben Ihrem Predigtdienst persönliche geistige Tätigkeiten beizubehalten. Sie haken sie auf einer Karte „Routine“ auf dem Startbildschirm ab. Sie ist kostenlos, freiwillig und funktioniert auf iPhone und Android.

## Einrichten

1. Tippen Sie auf der Karte **Geistige Routine** auf dem Startbildschirm auf **Einrichten**. Oder öffnen Sie **Einstellungen → Präferenzen → Geistige Routine**.
2. Wählen Sie, welche Tätigkeiten dabei sein sollen.
3. Wählen Sie, wie Sie die Bibel lesen, Ihre Zusammenkunftstage und Ihren Abend der Familienanbetung.

Eine tägliche Erinnerung gibt es, aber sie bleibt aus, bis Sie sie einschalten. Wenn Sie auf der Karte auf dem Startbildschirm auf **Nicht jetzt** tippen, verschwindet sie. Sie können sie später in den Einstellungen einrichten.

## Dinge abhaken

Tippen Sie auf den Kreis am Ende eines Eintrags auf der Karte „Routine“. Wenn alles für heute erledigt ist, schrumpft die Karte zu **Heute alles erledigt**.

Was Sie abhaken können:

- **Bibellesen:** einmal am Tag. Sie können auch einem Leseplan folgen. Siehe [Wie funktionieren Bibellesepläne in der Geistigen Routine?](/help/routine/routine-reading-plans)
- **Persönliches Studium:** jeden Tag, an dem Sie studieren. Standardmäßig bittet die Karte darum, bis Sie in der Woche einmal studiert haben. Sie können das Ziel auf eine Zahl pro Woche oder auf bestimmte Tage ändern.
- **Vorbereitung auf die Zusammenkunft unter der Woche** und **Vorbereitung auf die Zusammenkunft am Wochenende:** je einmal pro Woche. Jede erscheint ab zwei Tagen vor der Zusammenkunft bis zum Tag der Zusammenkunft.
- **Familienanbetung:** einmal pro Woche, an dem Abend, den Sie wählen. Wenn Sie nicht mit Ihrer Familie zusammen sind, können Sie sie Persönlicher Anbetungsabend nennen.

## Mehr sehen

- Tippen Sie auf einen Eintrag selbst, nicht auf seinen Kreis, um seinen Bildschirm zu öffnen. Er zeigt eine Heatmap der Tage, die Sie abgehakt haben, und **Letzte Tage**, wo Sie einen vergessenen Tag bis zum Anfang der letzten Woche zurück abhaken können. Tippen Sie auf einen abgehakten Tag, um ihn rückgängig zu machen.
- Tippen Sie auf den Titel der Karte „Routine“, um jede Tätigkeit zu sehen, die Sie eingeschaltet haben, und wie oft Sie sie diesen Monat abgehakt haben.

## Gut zu wissen

- Es gibt keine Serien. Ein verpasster Tag zählt nie gegen Sie.
- Um die Karte auszublenden, bearbeiten Sie Ihren Startbildschirm und entfernen Sie die Geistige Routine. Oder schalten Sie die Funktion unter **Einstellungen → Präferenzen → Geistige Routine** aus. Nichts, was Sie abgehakt haben, geht verloren.

## Wenn etwas schiefgeht

- **Eine Tätigkeit ist nicht auf dem Startbildschirm:** Wöchentliche Tätigkeiten erscheinen nur an ihren Tagen, und das persönliche Studium wird ausgeblendet, sobald Sie Ihr Wochenziel erreicht haben. Prüfen Sie **Einstellungen → Präferenzen → Geistige Routine**.
- **Es stimmt immer noch nicht:** Nutzen Sie **Brauchen Sie immer noch Hilfe?** unter dieser Antwort, um dem Support zu schreiben.
