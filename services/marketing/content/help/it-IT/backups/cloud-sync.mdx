id: cloudSync
title: Cos'è Cloud Sync?
---

Cloud Sync mantiene uguali le tue registrazioni su tutti i tuoi dispositivi: iPhone, Android e web. Funziona tra un iPhone e un telefono Android ed è gratuito. Solo tu puoi leggere le tue registrazioni.

Una nuova installazione parte con Cloud Sync attivo. Vedi [Cloud Sync è attivo in modo predefinito?](/help/backups/cloud-sync-default).

## Guarda o cambia la tua sincronizzazione

1. Apri **Impostazioni → Sincronizzazione**.
2. Guarda quale opzione usa questo dispositivo, oppure scegli Cloud Sync, iCloud (Google Drive su Android) o Disattivata.

## Da sapere

- I tuoi dispositivi si sincronizzano solo con dispositivi che usano la stessa opzione, quindi scegli la stessa su ciascuno. Le modifiche di solito arrivano in pochi secondi mentre l'app è aperta.
- Anche la tua foto del profilo, le foto dei contatti e le foto negli appunti si sincronizzano. Vedi [Le foto si sincronizzano con Cloud Sync?](/help/backups/cloud-sync-photos).
- Il web funziona solo con Cloud Sync. Se il tuo telefono usa qualcos'altro, il web chiede di attivarlo. Vedi [Perché il mio telefono è passato a Cloud Sync?](/help/backups/cloud-sync-from-web).
- Un telefono nuovo che configuri con il codice QR o la chiave di recupero del tuo account riceve le tue registrazioni tramite Cloud Sync. Non serve ripristinare.
- Se il tuo backup più recente è più recente delle tue copie di Cloud Sync, il telefono nuovo propone di ripristinare anche quello.
- Aggiorna WitnessWork se ti chiede l'accesso Sostenitore per usare Cloud Sync.

## Se qualcosa va storto

- **In Impostazioni → Sincronizzazione c'è scritto che Cloud Sync è in pausa o non è ancora disponibile:** le tue modifiche restano su questo dispositivo e si sincronizzano quando torna disponibile. Tocca **Sincronizza ora** per controllare di nuovo.
