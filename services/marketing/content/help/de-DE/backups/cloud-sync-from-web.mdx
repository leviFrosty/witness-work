---
id: cloudSyncFromWeb
title: Warum wurde mein Smartphone auf Cloud Sync umgestellt, nachdem ich mich im Web angemeldet habe?
---

Wenn Sie sich im Web anmelden, werden Sie gebeten, [Cloud Sync](/help/backups/cloud-sync) einzuschalten, weil das Web nur mit Cloud Sync funktioniert. Wenn Sie **Einschalten** wählen, wechselt Ihr Smartphone beim nächsten Öffnen von WitnessWork zu Cloud Sync.

## Nichts geht verloren

- Ihr Smartphone behält jeden Eintrag und jedes Foto und führt sie mit dem zusammen, was schon in Cloud Sync ist.
- Nichts, was Sie gelöscht haben, kommt zurück.
- Ihre anderen Smartphones mit demselben Konto wechseln ebenfalls, jedes beim nächsten Öffnen von WitnessWork.
- Ihre Einträge sind privat. Nur Ihre eigenen Geräte können sie lesen.

## Zurückwechseln

1. Öffnen Sie auf Ihrem Smartphone **Einstellungen → Sync**.
2. Wählen Sie iCloud (auf Android Google Drive) oder Aus.

Ihr Smartphone bleibt bei der Option, die Sie wählen. Das Web fragt beim nächsten Mal wieder.

## Wenn es nicht wechselt

- Achten Sie darauf, dass Ihr Smartphone online ist und Sie die Einrichtung von WitnessWork abgeschlossen haben, und öffnen Sie die App erneut.
- Wenn das Web **WitnessWork auf Ihrem Smartphone aktualisieren** anzeigt, aktualisieren Sie die App im App Store oder bei Google Play und öffnen Sie sie dann.
- Sie können Cloud Sync jederzeit selbst unter **Einstellungen → Sync** wählen.
