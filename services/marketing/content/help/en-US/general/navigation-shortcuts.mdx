---
id: navigationShortcuts
title: How do I navigate with keyboard shortcuts on iPad?
category: general
platforms:
  - ios
---

Connect a hardware keyboard to an iPad running iPadOS 26 or later, then hold Command while the main navigation is visible. Small shortcut labels appear beside the bottom tabs or sidebar items. Press Command and the displayed number to open that screen; release Command to hide the labels. Numbers follow the visible navigation order, so by default Home is Command 1 and Contacts is Command 2. Other numbers depend on which items are visible, including Buddies (from version 1.46.0, when Buddies is on) and Settings in the sidebar. Close any open form or other screen before using these navigation shortcuts; they do not save or discard records. Only shortcut use is measured, not what you type. Support requires an installed app build with the keyboard feature and is unavailable on iPhone and Android. If labels do not appear, check that the keyboard is connected, return to the main navigation, and update and reopen the app. You can always tap navigation items instead. For other problems, use the Help Center's private support link and keep contact details out of public reports.
