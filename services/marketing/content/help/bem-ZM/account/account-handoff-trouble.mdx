title: Nga ukwingila na QR code takubomba, nshi nshingacita?
---

Pangeni code ipya pa foni yenu ya kale elyo mwiisikene nakabili. Code imo imo ibomba umuku umo elyo ikashala pa mamineti 10.

## Esheni ifi

1. Pa foni ya kale, tinikeni **Make a New Code**.
2. Moneni ukuti foni yonse yabili yaba pa intaneti.
3. Sikeneni code ipya na foni ipya.
4. Moneni ukuti foni yonse yabili yalanga code imo ya nambala sita, elyo mutinike **Suminisha** pa foni ya kale.

## Nga cabipa

- **Ama code tayalingana:** tinikeni **Mwasuminisha** elyo mutendeke nakabili. Umbi kuti asikene code yenu.
- **Ukwingila kwapwa ilyo mwatinika YES:** shaleni na foni yonse yabili pa cikope. Foni ipya ilanga **Try Again** elyo itwalilila pa lwakwe ilyo yabwela pa intaneti.
- **Foni ya kale ilanda ukuti akaunti yenu taitumwa:** moneni intaneti yaiko elyo mutinike **Suminisha** nakabili.
- **Foni ipya tailesikena:** mu ifyo mwasala fya foni yenu, leseni WitnessWork ibomfye camera.
- **Foni ipya tailemoneka ukuti ni yeka:** bikeni WitnessWork ukufuma ku App Store nelyo Google Play. Moneni [Cinshi WitnessWork ilanda ukuti tailingashinina icibombelo ici?](/help/account/account-verification).
- **Tamwakwata foni yenu ya kale:** pa foni ipya, yeni ku **Ifyo Mwasala → Akaunti → Bomfya Icisokoshi ca Kubwesha**. Moneni [Nga naloba ukwingila mu akaunti yandi ya WitnessWork?](/help/account/lost-access).

Nacili ukuyafya? Washeni support ukufuma mu Help Center. Mwekutuma icisokoshi cenu ca kubwesha kuli umbi.
