title: Was ist Cloud Sync?
---

Cloud Sync hält Ihre Einträge auf allen Ihren Geräten gleich: iPhone, Android und im Web. Es funktioniert zwischen einem iPhone und einem Android-Smartphone und ist kostenlos. Nur Sie können Ihre Einträge lesen.

Eine neue Installation startet mit eingeschaltetem Cloud Sync. Siehe [Ist Cloud Sync standardmäßig eingeschaltet?](/help/backups/cloud-sync-default).

## Ihre Synchronisierung ansehen oder ändern

1. Öffnen Sie **Einstellungen → Sync**.
2. Sehen Sie, welche Option dieses Gerät nutzt, oder wählen Sie Cloud Sync, iCloud (auf Android Google Drive) oder Aus.

## Gut zu wissen

- Ihre Geräte synchronisieren nur mit Geräten, die dieselbe Option nutzen. Wählen Sie also auf jedem dieselbe. Änderungen kommen meist innerhalb von Sekunden an, solange die App geöffnet ist.
- Ihr Profilfoto, Kontaktfotos und Fotos in Notizen werden ebenfalls synchronisiert. Siehe [Werden Fotos mit Cloud Sync synchronisiert?](/help/backups/cloud-sync-photos).
- Das Web funktioniert nur mit Cloud Sync. Wenn Ihr Smartphone etwas anderes nutzt, bittet das Web darum, es einzuschalten. Siehe [Warum wurde mein Smartphone auf Cloud Sync umgestellt?](/help/backups/cloud-sync-from-web).
- Ein neues Smartphone, das Sie mit dem QR-Code oder dem Wiederherstellungsschlüssel Ihres Kontos einrichten, bekommt Ihre Einträge über Cloud Sync. Sie müssen nichts wiederherstellen.
- Wenn Ihre neueste Sicherung neuer ist als Ihre Cloud-Sync-Kopien, bietet das neue Smartphone an, auch sie wiederherzustellen.
- Aktualisieren Sie WitnessWork, wenn es für Cloud Sync Zugang als Unterstützer verlangt.

## Wenn etwas schiefgeht

- **Unter Einstellungen → Sync steht, dass Cloud Sync pausiert oder noch nicht verfügbar ist:** Ihre Änderungen bleiben auf diesem Gerät und werden synchronisiert, sobald es wieder geht. Tippen Sie auf **Jetzt synchronisieren**, um erneut zu prüfen.
