---
id: webLinks
title: Kann ich einen geteilten Kontakt oder eine Buddies-Einladung im Web öffnen?
---

Ja. Wenn Sie die WitnessWork-App auf diesem Gerät nicht haben, bietet die Seite des Links **Im Web fortfahren** an. Das öffnet WitnessWork unter [app.witnesswork.app](https://app.witnesswork.app).

## Einen geteilten Kontakt öffnen

1. Tippen Sie auf den Link und wählen Sie **Im Web fortfahren**.
2. Melden Sie sich an, falls Sie gefragt werden.
3. Wenn WitnessWork **Kontakt importieren?** fragt, wählen Sie **OK**, um ihn hinzuzufügen, oder **Stornieren**, um ihn wegzulassen.

Nichts wird gespeichert, bevor Sie wählen.

## Eine Buddies-Einladung öffnen

1. Tippen Sie auf den Link und wählen Sie **Im Web fortfahren**.
2. Melden Sie sich an, falls Sie gefragt werden.
3. Prüfen Sie, wer Sie eingeladen hat, und nehmen Sie dann an.

## Gut zu wissen

- Wenn WitnessWork gesperrt oder in einem anderen Tab geöffnet ist, entsperren Sie es oder wählen Sie zuerst **Hier verwenden**. Der Kontakt oder die Einladung öffnet sich direkt danach.
- WitnessWork hält einen Link, den Sie noch nicht geöffnet haben, bis zu eine Stunde lang bereit. Danach öffnen Sie den Link erneut.
- Das Neuladen der Seite oder ein Screenshot davon zeigt den Kontakt oder die Einladung nicht.
- Eine Buddies-Einladung funktioniert einmal und läuft nach sieben Tagen ab.

## Wenn etwas schiefgeht

- **Der Link ist ungültig:** Er wurde beim Kopieren gekürzt oder verändert. Bitten Sie den Absender, ihn noch einmal zu teilen. Siehe [Probleme mit einer Buddies-Einladung](/help/buddies/buddies-invite-trouble).
