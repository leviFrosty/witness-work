---
id: timeRollover
title: Mon temps est-il automatiquement reporté sur le mois suivant ?
---

Oui, si vous l’activez. Les heures qu’il vous manque pour votre objectif mensuel peuvent être reportées sur le mois suivant.

## Activer le report

1. Ouvrez **Paramètres → Profil → Avancé**.
2. Activez **Report automatique de l’heure**.

![Réglages avancés du profil avec le commutateur Report automatique de l’heure](time-rollover.webp)

Il n’apparaît que si vous enregistrez des heures. Les heures reportées apparaissent quand le nouveau mois commence, vous n’avez donc rien à soustraire ni à ressaisir.
