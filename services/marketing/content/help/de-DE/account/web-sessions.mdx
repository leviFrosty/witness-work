id: webSessions
title: Wie lange bleibt ein Browser angemeldet, und wie viele kann ich nutzen?
---

Ein Browser bleibt angemeldet, solange Sie ihn nutzen, sodass WitnessWork im Web direkt mit Ihren Daten öffnet. Die Anmeldung endet nach 180 Tagen ohne Nutzung oder wenn Sie sich abmelden.

Sie können bis zu 3 Browser gleichzeitig angemeldet haben, getrennt von Ihren Smartphones. Wenn Sie einen vierten anmelden, wird der abgemeldet, den Sie am längsten nicht genutzt haben.

## Ihre Browser ansehen und abmelden

1. Öffnen Sie **Einstellungen → Konto → Angemeldete Geräte**, auf einem Smartphone oder im Web.
2. Tippen Sie auf einen Browser, etwa „Chrome auf macOS“.
3. Wählen Sie **Abmelden**.

Ein Browser, den Sie von einem anderen Gerät aus abmelden, wird gelöscht, sobald er sich das nächste Mal verbindet. Alles, was er noch nicht abgeglichen hatte, geht verloren. Wie Sie den Browser abmelden, den Sie gerade nutzen, lesen Sie unter [Wie melde ich mich im Web von WitnessWork ab?](/help/account/web-sign-out).

## Gut zu wissen

- Eine neue Anmeldung erscheint auf Ihren anderen Geräten in der Glocke auf dem Startbildschirm und unter **Einstellungen → Konto → Kontoaktivität**. Wenn eine nicht von Ihnen ist, tippen Sie darauf, melden Sie dieses Gerät ab und ändern Sie Ihren Kontoschlüssel. Siehe [Was tue ich, wenn mein Smartphone oder Computer verloren geht oder gestohlen wird?](/help/account/lost-device).
- Einige Minuten nach der Anmeldung können Sie einen Passkey hinzufügen oder entfernen oder Ihren Wiederherstellungsschlüssel ansehen, ohne zu bestätigen. Danach bittet WitnessWork Sie, einen Passkey zu nutzen.
- Kein Passkey auf diesem Computer? Wählen Sie **Erneut anmelden** und melden Sie sich mit Ihrem Wiederherstellungsschlüssel oder Ihrem Smartphone an. Nutzen Sie dasselbe Konto. Ihre Daten bleiben im Browser.
- Um WitnessWork zu verbergen, wenn Sie weggehen, schalten Sie die App-Sperre ein. Siehe [Wie sperre ich WitnessWork?](/help/general/app-lock).
