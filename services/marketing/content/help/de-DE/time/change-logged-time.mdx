---
id: changeLoggedTime
title: Wie ändere oder lösche ich Zeit, die ich schon erfasst habe?
---

Öffnen Sie **Zeit hinzufügen**, wählen Sie den Tag und tippen Sie auf den Eintrag, den Sie ändern oder löschen möchten.

## Einen Eintrag ändern

1. Öffnen Sie auf **Start** **Zeit hinzufügen**. Sie können auch die Taste **+** nutzen.
2. Tippen Sie in der Tagesleiste oben auf den Tag. Um einen anderen Tag zu wählen, tippen Sie auf das Datum darüber.
3. Tippen Sie in der Liste unter den Tagen auf den Eintrag.
4. Ändern Sie die Zeit, den Typ oder die Notiz. Um ihn zu verschieben, tippen Sie auf einen anderen Tag.
5. Tippen Sie auf **Speichern**.

Um einen Eintrag zu verlassen, ohne zu speichern, tippen Sie ihn noch einmal an. Wenn Sie etwas geändert haben, fragt WitnessWork nach, bevor es die Änderung verwirft.

## Einen Eintrag löschen

1. Öffnen Sie **Zeit hinzufügen** und wählen Sie den Tag.
2. Halten Sie den Eintrag gedrückt und wählen Sie dann **Löschen**. Im Web klicken Sie mit der rechten Maustaste darauf.

Das Löschen kann nicht rückgängig gemacht werden.

## Gut zu wissen

- Ein Tag mit mehr als drei Einträgen zeigt die ersten zwei. Tippen Sie auf **Mehr anzeigen**, um den Rest zu sehen.
- Um Zeit an mehreren Tagen zu erfassen, fügen Sie den ersten Eintrag hinzu und tippen Sie dann in der Bestätigung auf **Weiteren hinzufügen**.
- Zeit erfassen wird nur angezeigt, wenn Ihr Status Stunden erfasst. Königreichsverkündiger schalten zuerst **Meine Stunden erfassen** unter **Einstellungen → Profil** ein.
- Sie können einen Eintrag auch von seinem Tag aus ändern. Siehe [Wie erfasse ich Zeit oder plane einen bestimmten Tag?](/help/time/log-time-for-day)
