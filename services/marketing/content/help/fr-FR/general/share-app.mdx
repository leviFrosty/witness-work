title: Comment partager WitnessWork avec un ami ?
---

Ouvrez **Paramètres → Partager WitnessWork** et montrez un code à votre ami ou envoyez-lui un lien. WitnessWork est gratuit sur iPhone comme sur Android.

## Partager avec un code

1. Touchez votre photo de profil, puis **Paramètres → Partager WitnessWork**.
2. Choisissez **Android** ou **iPhone**.
3. Votre ami scanne le code avec l’appareil photo de son téléphone pour ouvrir WitnessWork dans Google Play ou l’App Store.

## Partager avec un lien

Touchez **Partager le lien**. Le message contient les deux liens de boutique, il convient donc à tout le monde.

## Bon à savoir

- Le message ne contient que les liens de boutique. Il ne dit rien de vous ni de vos enregistrements.

## En cas de problème

- **Un code ne se scanne pas :** augmentez la luminosité de votre écran, ou utilisez plutôt **Partager le lien**.
