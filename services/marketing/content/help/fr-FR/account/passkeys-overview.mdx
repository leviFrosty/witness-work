title: Qu’est-ce qu’une clé d’accès, et comment en enregistrer une pour WitnessWork ?
---

Une clé d’accès vous permet de vous connecter avec Face ID, votre empreinte ou le verrouillage de votre écran, sans mot de passe. C’est un autre moyen d’entrer dans le même compte, et vous n’en avez pas besoin.

Une clé d’accès peut vous connecter sur app.witnesswork.app ou sur un nouveau téléphone. Une clé qui peut déverrouiller votre compte l’amène aussi sur un nouveau navigateur ou téléphone, sans autre appareil et sans clé de récupération.

## Enregistrer une clé d’accès

1. Ouvrez **Paramètres → Compte → Clés d’accès**.
2. Touchez **Ajouter une clé d’accès**.
3. Confirmez avec Face ID, votre empreinte ou votre code.

Pendant la configuration, WitnessWork peut proposer **Enregistrer une clé d’accès**. Touchez **Pas maintenant** pour passer. Vous pouvez en avoir jusqu’à 10.

Sur le web, vous pouvez en ajouter une depuis le même écran. Si votre compte n’a encore aucune clé d’accès, ajoutez la première dans l’application sur téléphone, ou dans les minutes qui suivent votre connexion sur le web.

## Se connecter avec une clé d’accès

- **Sur le web :** sur app.witnesswork.app, choisissez **Se connecter avec une clé d’accès**.
- **Sur un nouveau téléphone :** pendant la configuration, touchez **J’utilise déjà WitnessWork**, puis **Se connecter avec une clé d’accès**. Plus tard, utilisez **Paramètres → Compte → Se connecter avec une clé d’accès**.

Si la clé d’accès vous connecte mais ne peut pas déverrouiller votre compte, terminez avec **Utiliser votre autre téléphone** ou **Utiliser plutôt une clé de récupération**. Après cela, elle peut généralement déverrouiller toute seule la fois suivante.

## Bon à savoir

- Si le téléphone a déjà un autre compte, il demande toujours avant de le remplacer.
- Les clés d’accès sur téléphone demandent iOS 16 ou une version plus récente, ou Android avec le Gestionnaire d’identifiants de Google. Sur iPhone, une clé d’accès ne peut déverrouiller votre compte qu’à partir d’iOS 18.
- Sur le web, avant d’afficher votre clé de récupération ou de modifier les clés d’accès, WitnessWork vous demande d’utiliser l’une de vos clés d’accès. Juste après votre connexion, il ne le demande pas. Voir [Combien de temps un navigateur reste-t-il connecté, et combien puis-je en utiliser ?](/help/account/web-sessions).
- WitnessWork peut vous rappeler d’enregistrer une clé d’accès dans la cloche sur l’Accueil. Si vous touchez **Pas maintenant** deux fois, les rappels s’arrêtent.
- Pour distinguer vos clés d’accès ou en retirer une, voir [Comment distinguer mes clés d’accès et comment en retirer une ?](/help/account/passkeys-manage).
