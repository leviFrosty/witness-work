title: "Cloud Sync ni iki?"
---

Cloud Sync ituma inyandiko zawe zingana ku bikoresho byawe byose: iPhone, Android na murandasi. Ikora hagati ya iPhone na telefoni ya Android, kandi ni ubuntu. Ni wowe wenyine usoma inyandiko zawe.

WitnessWork nshya itangirana na Cloud Sync ifunguye. Reba [Cloud Sync ifunguye mu buryo busanzwe?](/help/backups/cloud-sync-default).

## Reba cyangwa uhindure guhuza kwawe

1. Fungura **Igenamiterere → Guhuza**.
2. Reba uburyo iki gikoresho gikoresha, cyangwa uhitemo Cloud Sync, iCloud (Google Drive kuri Android), cyangwa Zimya.

## Byiza kumenya

- Ibikoresho byawe bihuza gusa n'ibikoresho biri ku buryo bumwe, bityo hitamo bumwe kuri buri kimwe. Impinduka akenshi zigera mu masegonda mike porogaramu ifunguye.
- Ifoto yawe y'umwirondoro, amafoto y'abantu n'amafoto ari mu nyandiko na byo birahuzwa. Reba [Amafoto ahuzwa na Cloud Sync?](/help/backups/cloud-sync-photos).
- Murandasi ikorana na Cloud Sync gusa. Niba telefoni yawe ikoresha ikindi, murandasi isaba kuyifungura. Reba [Kuki telefoni yanjye yahinduye ikajya kuri Cloud Sync?](/help/backups/cloud-sync-from-web).
- Telefoni nshya ushyizeho ukoresheje QR code ya konti yawe cyangwa urufunguzo rwo kugarura ibona inyandiko zawe ikoresheje Cloud Sync. Nta byo gukeneye kugarura.
- Niba backup yawe nshya iruta kopi zawe za Cloud Sync, telefoni nshya itanga no kuyigarura.
- Vugurura WitnessWork niba ikubwira ko ukeneye kuba Umufasha kugira ngo ukoreshe Cloud Sync.

## Iyo hari ikitagenze neza

- **Igenamiterere → Guhuza ivuga ko Cloud Sync yahagaze cyangwa itaraboneka:** impinduka zawe zigumya kuri iki gikoresho kandi zihuzwa isubiye. Kanda **Huza ubu** kugira ngo urebe bundi bushya.
