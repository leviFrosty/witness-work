title: Comment signaler un bug ou demander une fonctionnalité ?
---

Utilisez les boutons ci-dessous pour signaler un bogue ou demander une fonction. Indiquez les étapes pour le reproduire, ce que vous attendiez, votre appareil et la version de votre système d’exploitation, ainsi que la version de WitnessWork affichée sous Vous avez toujours besoin d’aide ?. Retirez des signalements et captures d’écran publics les coordonnées privées, les notes, les identifiants de compte, ainsi que les codes et liens d’invitation Compagnons. Pour une sauvegarde ou d’autres problèmes sensibles, utilisez plutôt le lien e-mail privé sous Vous avez toujours besoin d’aide ?. Le code source, la Politique de confidentialité et les Conditions d’utilisation se trouvent dans Paramètres → À propos.
