---
id: cloudSyncDefault
title: Ist Cloud Sync standardmäßig eingeschaltet?
---

Ja. Eine neue Installation von WitnessWork startet mit eingeschaltetem Cloud Sync, und Ihre Einträge und Fotos werden zwischen Ihren Geräten synchronisiert. Nur Sie können sie lesen.

## Einträge auf einem Gerät behalten

1. Suchen Sie bei der Einrichtung den Schritt für Cloud Sync.
2. Schalten Sie den Schalter **Cloud Sync** aus.

Dann wird nichts synchronisiert, und Sie können es später unter **Einstellungen → Sync** einschalten.

## Wenn Sie WitnessWork schon genutzt haben

Ihre Einstellung ändert sich nicht. Eine Meldung in Ihren Benachrichtigungen, der Glocke auf dem Startbildschirm, bietet Ihnen möglicherweise **Einschalten** oder **Cloud Sync einschalten** an. Tippen Sie darauf, um zu wechseln, oder blenden Sie sie aus. Sie kommt nicht wieder.

- Wenn Sie mit iCloud synchronisieren (auf Android mit Google Drive), bleibt das so, bis Sie es ändern.
- Wenn Sie die Synchronisierung ausgeschaltet haben, bleibt sie aus.

## Gut zu wissen

- Um es auf einem Gerät zu ändern, öffnen Sie **Einstellungen → Sync** und wählen Sie Cloud Sync, iCloud (auf Android Google Drive) oder Aus.
- Ihre Geräte synchronisieren nur mit Geräten, die dieselbe Option nutzen. Wählen Sie also auf jedem dieselbe.
- WitnessWork im Web nutzt nur Cloud Sync.
- Beim Wechseln werden nie Einträge ersetzt, und nichts, was Sie gelöscht haben, kommt zurück.
