title: What is Cloud Sync?
category: backups
pinned: true
---

Cloud Sync keeps your records the same on all your devices, including between an iPhone and an Android phone, and it's what WitnessWork on the web uses. Each device that uses it keeps an end-to-end encrypted copy of its data on WitnessWork's server, and your other devices on Cloud Sync combine those copies, usually within seconds while the app is open. Cloud Sync is included for everyone, along with iCloud Sync and Google Drive Sync. From version 1.47.0, a new install starts with Cloud Sync on; see “Is Cloud Sync on by default?”. Open Settings → Device Sync to see which option this device uses, turn sync off, or switch to iCloud (Google Drive on Android). A device syncs one way at a time, and only with your devices that use the same option. From version 1.47.0, your profile photo, contact photos and photos in notes sync with Cloud Sync too, end-to-end encrypted, using your account's 2 GB of photo storage (see “Do photos sync with Cloud Sync?”); with an older version they stay on the device that added them. WitnessWork on the web works only with Cloud Sync; if your phone uses iCloud (Google Drive on Android) or has sync off, the web asks to turn it on. Versions older than 1.47.0 may still ask for Supporter access to use Cloud Sync, so update WitnessWork. If WitnessWork has paused Cloud Sync for a while, or says Cloud Sync isn't available for your account yet, Settings → Device Sync says so; your changes stay on this device and sync once it's back, and Sync now checks again. A new phone you set up from your account's QR code or recovery key gets your records through Cloud Sync without a restore step. If your newest backup is newer than every Cloud Sync copy, for example from a phone that stayed on iCloud, the new phone offers to restore it too.
