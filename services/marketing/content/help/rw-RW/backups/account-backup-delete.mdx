title: "Nasiba nte backup yanjye, kandi imara igihe kingana iki?"
---

Fungura **Igenamiterere → Konti**. Kanda backup y'igikoresho kugira ngo usibe iyo gusa, cyangwa ukande **Siba backup** kugira ngo usibe backup z'ibikoresho byawe byose. Backup zisibwe zihita zivaho, kandi backup izima kuri iyi telefoni.

## Byiza kumenya

- Kuzimya **Kora backup kuri WitnessWork** bibaza niba usiba na backup y'iyi telefoni.
- Ikindi gikoresho gifite backup ifunguye kizongera gukora backup ubutaha ufunguye WitnessWork kuri cyo.
- Backup y'igikoresho itavuguruwe mu minsi 400 isibwa yonyine.
- **Siba amakuru yanjye ya Buddies** mu igenamiterere rya Buddies isiba na backup yawe. Niba backup ifunguye, backup yawe ikurikira ijya kuri konti yawe nshya.

## Iyo hari ikitagenze neza

- **Wari nta murandasi:** nta kintu cyasibwe. Ongera ugerageze usubiye kuri murandasi.
