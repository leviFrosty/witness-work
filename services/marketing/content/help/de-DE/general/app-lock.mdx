id: appLock
title: Wie sperre ich WitnessWork mit Gesicht, Fingerabdruck, Code oder Passkey?
---

Sie können WitnessWork so einstellen, dass es bei jedem Öffnen nach Ihrem Gesicht, Fingerabdruck oder Code fragt.

## Die Sperre einschalten

1. Öffnen Sie **Einstellungen → Datenschutz**.
2. Schalten Sie **Face ID verlangen** ein. Auf anderen Smartphones heißt es **Touch ID verlangen**, **Code verlangen** oder, auf Android, **Biometrische Entsperrung verlangen**.
3. Bestätigen Sie, dass Sie es sind.
4. Wählen Sie unter **Verlangen**, wie bald WitnessWork wieder fragt, nachdem Sie es verlassen haben: sofort oder nach 1, 5 oder 15 Minuten.

## Die Sperre ausschalten

Öffnen Sie **Einstellungen → Datenschutz**, schalten Sie den Schalter aus und bestätigen Sie, dass Sie es sind.

## Gut zu wissen

- Wenn Ihr Gesicht oder Fingerabdruck nicht erkannt wird, nutzen Sie den Code, die PIN, das Muster oder das Passwort Ihres Smartphones.
- Die Sperre gilt nur auf dem Smartphone, auf dem Sie sie einschalten. Schalten Sie sie auf jedem Gerät einzeln ein.
- Ihr Smartphone braucht einen Code oder eine Bildschirmsperre. Falls es keine hat, tippen Sie auf **Einstellungen öffnen**, wenn WitnessWork fragt, richten Sie eine ein und schalten Sie die Sperre dann erneut ein.
- Solange die Sperre an ist, zeigt der App-Umschalter eine leere Karte. Auf Android braucht das Android 13 oder neuer.
- Die Sperre schützt nur die App. Widgets, Benachrichtigungen, Siri und Ihre Uhr zeigen weiterhin das Gewohnte.
- Wenn Sie auf eine Erinnerung oder einen Link tippen, während WitnessWork gesperrt ist, öffnet er sich nach dem Entsperren.

## Im Web

Die Sperre im Web nutzt einen Passkey. Ihr Konto braucht also zuerst einen. Siehe [Was ist ein Passkey?](/help/account/passkeys-overview).

1. Öffnen Sie **Einstellungen → Datenschutz**.
2. Schalten Sie **Passkey verlangen** ein und bestätigen Sie mit Ihrem Passkey. Dafür müssen Sie online sein.
3. Wählen Sie unter **Verlangen** 1, 5 oder 15 Minuten. Im Web gibt es die Option „sofort“ nicht.

Zum Entsperren klicken Sie auf **Mit Passkey entsperren**. Um die Sperre auszuschalten, schalten Sie den Schalter aus und nutzen Sie Ihren Passkey erneut.

- Die Sperre gilt nur für diesen Browser. Beim Abmelden wird sie ausgeschaltet.
- Sie verbirgt WitnessWork bis zum Entsperren, meldet Sie aber nicht ab. Melden Sie sich auf einem gemeinsam genutzten Computer ab, wenn Sie fertig sind.
- Wenn Sie alle Passkeys, die sie nutzt, aus Ihrem Konto entfernen, schaltet sich die Sperre von selbst aus.

## Wenn etwas schiefgeht

- **Das Entsperren auf Ihrem Smartphone schlägt immer wieder fehl:** Prüfen Sie, ob Ihr Code auf dem Sperrbildschirm funktioniert. Beenden Sie dann WitnessWork vollständig und öffnen Sie es erneut.
- **Keiner Ihrer Passkeys ist im Web verfügbar:** Wählen Sie auf dem Sperrbildschirm **Abmelden** und melden Sie sich erneut an. Alles, was dieser Browser noch nicht synchronisiert hatte, wird gelöscht.
- **Es klappt immer noch nicht:** Nutzen Sie den privaten Support-Link im Hilfezentrum und lassen Sie persönliche Angaben aus öffentlichen Berichten heraus.
