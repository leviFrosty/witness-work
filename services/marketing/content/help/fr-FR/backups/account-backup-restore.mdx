id: accountBackupRestore
title: Comment restaurer ma sauvegarde sur un nouveau téléphone ?
---

Installez WitnessWork sur le nouveau téléphone, connectez-vous à votre compte, puis restaurez votre sauvegarde quand l’application vous le propose.

## Se connecter sur le nouveau téléphone

Si vous avez encore votre ancien téléphone :

1. Sur l’ancien téléphone, ouvrez **Paramètres → Compte → Configurer un autre appareil**.
2. Sur le nouveau téléphone, pendant la configuration, touchez **J’utilise déjà WitnessWork**, puis **Depuis votre autre téléphone**.
3. Scannez le code affiché sur l’ancien téléphone.

Si vous n’avez plus votre ancien téléphone, ouvrez **Paramètres → Compte → Utiliser une clé de récupération** sur le nouveau téléphone et saisissez votre clé.

## Restaurer votre sauvegarde

1. Quand le nouveau téléphone propose votre sauvegarde, touchez **Restaurer**.
2. Si le téléphone contient déjà des enregistrements, choisissez **Fusionner** pour les garder et ajouter ceux de la sauvegarde, ou **Remplacer** pour n’utiliser que la sauvegarde.
3. Activez aussi **Sauvegarder sur WitnessWork** sur le nouveau téléphone.

Vous pouvez aussi restaurer plus tard depuis **Paramètres → Compte → Restaurer depuis la sauvegarde**.

## Bon à savoir

- Si vos autres appareils utilisent [Cloud Sync](/help/backups/cloud-sync), vos enregistrements arrivent par ce moyen à la place.
- Si vous avez des sauvegardes de plusieurs appareils, la restauration les combine.
- Une sauvegarde faite avec une version plus récente de WitnessWork est laissée de côté tant que vous ne mettez pas à jour. L’application vous le dit quand cela arrive.
