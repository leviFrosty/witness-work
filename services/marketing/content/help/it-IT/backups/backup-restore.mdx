title: Come faccio il backup dei miei dati e come li ripristino?
---

Salva un file di backup in **Impostazioni → Backup e ripristino** e ripristinalo dallo stesso posto. Il file funziona su iPhone, Android e web, quindi puoi usarlo anche per spostare le tue registrazioni dall'uno all'altro.

Per un backup automatico, vedi [Cos'è il Backup di WitnessWork?](/help/backups/account-backup).

## Crea un file di backup

1. Apri **Impostazioni → Backup e ripristino**.
2. Tocca **Crea backup**.
3. Scegli come proteggere il file. **Il mio account** si apre sui dispositivi in cui hai effettuato l'accesso al tuo account, o ovunque con la tua chiave di recupero. **Password** (almeno 8 caratteri) si apre su qualsiasi dispositivo con quella password, quindi usala per condividere una copia.
4. Salva il file, che si chiama witness-work-backup.json.

Sul web, il file viene scaricato nella cartella dei download del browser.

## Ripristina da un file di backup

1. Apri **Impostazioni → Backup e ripristino**.
2. Tocca **Ripristina da backup**.
3. Scegli il tuo file di backup. Inserisci la sua password, se ce l'ha.

Su un telefono nuovo, puoi invece toccare **Uso già WitnessWork** all'inizio della configurazione, poi scegliere **Da un file di backup** sotto **Altri modi per ripristinare** nella schermata **Bentornato**.

## Da sapere

- Un ripristino sostituisce su questo dispositivo le registrazioni incluse nel backup. Salva prima un backup aggiornato.
- Il file include rapporti di servizio, piani, contatti, visite, categorie, chilometri, il tuo animaletto, il profilo e le impostazioni condivise. Lascia fuori foto, auto condivise e le impostazioni di questo dispositivo.
- Nessuno può aprire un file protetto senza la sua password o il tuo account, e WitnessWork non può recuperare una password dimenticata.
- Un backup fatto con una versione più recente di WitnessWork non si può ripristinare finché non aggiorni.
- Tieni riservati il file e la sua password. Può contenere dati delle persone visitate.

## Se qualcosa va storto

- **Dice di accedere prima:** accedi al tuo account su questo telefono con **Accedi con codice QR** o con la tua chiave di recupero, poi riprova.
- **Dice che il file è protetto per un altro account:** ripristinalo su un dispositivo con l'accesso a quell'account, oppure crea lì un backup protetto da password.
- **Alcuni elementi non si sono potuti leggere:** il resto viene ripristinato e WitnessWork ti dice quanti ne ha lasciati fuori.
- **Ancora bloccato:** usa l'opzione di assistenza privata nel Centro di Assistenza.
