title: Posso importare i dati da MyTime, Ministry Assistant o un'altra app?
---

Puoi importare un backup di MyTime. I file di altre app non sono supportati, ma puoi incollare del testo leggibile in Scribe AI.

## Importa da MyTime

1. In MyTime, vai su **Altro → Impostazioni → Backup** e invia a te stesso un backup via email.
2. Salva sul tuo dispositivo il file .mytimedb allegato. Su Android o sul web, invialo da MyTime sul tuo iPhone e scarica l'allegato su quel dispositivo.
3. In WitnessWork, apri **Impostazioni → Importa dati → Da MyTime**. Durante la configurazione, scegli invece **Da MyTime**.
4. Scegli il file.
5. Controlla l'anteprima, poi importa.

## Da sapere

- Sul web, il file resta nel tuo browser e non viene caricato. Un file di oltre 25 MB viene rifiutato.
- Per un'altra app, prova a esportare del testo leggibile e a incollarlo in Scribe AI. Controlla cosa propone prima di salvare.
- I file di backup di WitnessWork vanno in **Impostazioni → Backup e ripristino**, non qui.
- Per portare dati da Note o dalla carta più tardi, usa **Impostazioni → Importa dati**.

## Se dice che il file non è un database

L'importazione richiede il file .mytimedb originale creato da MyTime. Un PDF, un'esportazione di testo, un backup di WitnessWork o un file rinominato non funzionano. Conserva il file originale senza modificarlo. Se un backup valido non funziona comunque, scrivi all'assistenza in privato indicando l'errore e la versione di WitnessWork. Non pubblicare il backup.
