title: Wie verwalte oder kündige ich ein Abo, das ich im Web gekauft habe?
---

Öffnen Sie Ihre Abo-Seite über WitnessWork im Web oder über eine E-Mail mit dem Beleg. Dort können Sie kündigen, Ihre Zahlungsmethode ändern und Ihre Belege ansehen.

## Ihre Abo-Seite öffnen

1. Öffnen Sie in WitnessWork im Web **Einstellungen → Abo verwalten**.
2. Wählen Sie **Verwalten**. Ihre Abo-Seite öffnet sich in einem neuen Tab.
3. Wenn sie nach Ihrer E-Mail-Adresse fragt, geben Sie die ein, die Sie beim Bezahlen genutzt haben.
4. Öffnen Sie den Anmeldelink, den sie Ihnen sendet.

Jede E-Mail mit einem Beleg führt ebenfalls zu dieser Seite, sodass Sie sie nutzen können, ohne sich bei WitnessWork anzumelden.

## Gut zu wissen

- Das Kündigen stoppt die nächste Verlängerung. Ihr Unterstützer-Zugang bleibt bis zum Ende des Zeitraums, den Sie bezahlt haben.
- Ein Trinkgeld ist einmalig. Es gibt nichts zu kündigen, und es wird nichts mehr abgebucht.
- Pausieren ist bei Abos aus dem Web nicht möglich. Sie können kündigen und jederzeit neu abonnieren.
- Die Smartphone-App kann kein Abo aus dem Web verwalten. Nutzen Sie das Web oder den Link in Ihrer E-Mail mit dem Beleg.
- Wenn Sie im App Store oder bei Google Play gekauft haben, öffnet **Verwalten** stattdessen die Abo-Seite dieses Stores.
- Wenn Sie in ein Land ziehen, in dem das Web nicht verkauft, werden Verlängerungen und Kartenwechsel mit einer Karte oder Rechnungsadresse von dort abgelehnt. Abonnieren Sie stattdessen im App Store oder bei Google Play.

## Wenn etwas schiefgeht

- **Kein Anmeldelink:** Prüfen Sie, ob Sie die E-Mail-Adresse eingegeben haben, die Sie beim Bezahlen genutzt haben, und sehen Sie in Ihrem Spam-Ordner nach.
- **Kein „Abo verwalten“ in den Einstellungen:** Ihr Unterstützer-Zugang ist kein Abo, das Sie dort ändern können, zum Beispiel eine kostenlose Gewährung.
- **Ihr Abo ist nicht zu finden:** Schreiben Sie an [support@witnesswork.app](mailto:support@witnesswork.app), von der Adresse, die Sie beim Bezahlen genutzt haben.

Wie Sie Geld zurückverlangen, lesen Sie unter [Kann ich für einen Kauf im Web eine Erstattung bekommen?](/help/supporter/web-purchase-refund).
