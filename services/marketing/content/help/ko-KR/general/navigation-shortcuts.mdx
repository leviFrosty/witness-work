title: iPad에서 키보드 단축키로 화면을 이동하려면 어떻게 하나요?
---

iPadOS 26 이상을 실행하는 iPad에 외장 키보드를 연결한 다음, 주 내비게이션이 보이는 상태에서 Command 키를 길게 누르세요. 하단 탭이나 사이드바 항목 옆에 작은 단축키 라벨이 나타납니다. Command 키와 표시된 숫자를 누르면 해당 화면이 열리고, Command 키에서 손을 떼면 라벨이 사라집니다. 숫자는 화면에 보이는 내비게이션 순서를 따르므로, 기본적으로 홈은 Command 1, 연락처는 Command 2입니다. 그 밖의 숫자는 사이드바의 설정을 포함해 어떤 항목이 보이는지에 따라 달라집니다. 이 내비게이션 단축키를 사용하기 전에 열려 있는 양식이나 다른 화면을 닫으세요. 단축키로는 기록이 저장되거나 폐기되지 않습니다. 단축키 사용 여부만 집계되며, 입력하는 내용은 집계되지 않습니다. 이 기능은 키보드 기능이 포함된 설치된 앱 빌드가 필요하며 iPhone과 Android에서는 사용할 수 없습니다. 라벨이 나타나지 않으면 키보드가 연결되어 있는지 확인하고, 주 내비게이션으로 돌아간 뒤 앱을 업데이트하고 다시 여세요. 언제든 내비게이션 항목을 직접 탭해도 됩니다. 다른 문제는 도움말 센터의 비공개 지원 링크를 이용하시고, 공개 신고에는 연락처 정보를 포함하지 마세요.
