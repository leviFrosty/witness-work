title: 我要如何把 WitnessWork 安裝到主畫面或桌面上？
---

你可以在瀏覽器分頁中使用 WitnessWork，也可以安裝它，讓它像 App 一樣在自己的視窗中開啟。兩種方式都是同一個 App。

## 安裝它

- **電腦上的 Chrome 或 Edge：**開啟 app.witnesswork.app，使用網址列中的安裝圖示，或選單中的**安裝**項目。
- **Mac 上的 Safari：**開啟**檔案**選單，選擇**加入 Dock**。
- **iPhone 或 iPad：**在 Safari 中點**分享**，再點**加入主畫面**。
- **Android：**在 Chrome 中，點最上方**安裝應用程式**橫幅上的**安裝**，然後確認。或者使用瀏覽器的選單，選擇**安裝應用程式**或**新增到主畫面**。

## 注意事項

- iPhone 主畫面上的網頁 App，即使你有一段時間沒開啟，也會保留它的資料。請見[WitnessWork 在我的瀏覽器中保存了什麼？](/help/general/web-storage)。
- 在 iPhone 和 iPad 上，Safari 會改顯示 Apple 的 App Store App 橫幅。
- 用橫幅上的 X 關閉**安裝應用程式**橫幅。在那個瀏覽器的網站資料被清除，或你登出之前，它都會維持關閉。
- 在電腦上，或 WitnessWork 已經安裝之後，就不會有橫幅。
