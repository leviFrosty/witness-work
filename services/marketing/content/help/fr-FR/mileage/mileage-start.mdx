id: mileageStart
title: Comment suivre mon kilométrage ?
---

Le suivi du kilométrage est facultatif et disponible pour tous les types de proclamateurs. Répondez Oui sur la carte « Suivre le kilométrage ? » de l’Accueil, ou activez Suivre le kilométrage dans Paramètres → Préférences → Proclamateur. Ajoutez ensuite votre première voiture ; seul un nom est requis. Enregistrez un trajet avec Enregistrer un trajet sur la carte Kilométrage de l’Accueil, depuis le bouton Ajouter, ou sur l’écran Kilométrage. Saisissez la distance (activez Aller-retour pour la doubler) ou passez à Compteur kilométrique et saisissez les relevés de départ et d’arrivée. Le relevé de départ se remplit à partir du dernier relevé de cette voiture. Les trajets ne peuvent pas être datés dans le futur. Touchez un trajet pour voir ses détails, ou appuyez longuement dessus pour le modifier, l’enregistrer de nouveau aujourd’hui, le partager ou le supprimer.
