id: changeAccountKey
title: Wie ändere ich meinen Kontoschlüssel?
---

Ändern Sie ihn, wenn Sie ein Gerät verloren haben oder glauben, dass jemand anderes Ihren Wiederherstellungsschlüssel hat. Ihr Konto, Ihr Unterstützerstatus, Ihre Cloud-Sync-Daten und Ihre Sicherungen bleiben erhalten. Nur der Schlüssel ändert sich, und der alte funktioniert nirgends mehr.

## Bevor Sie anfangen

- Wenn Sie ein iPhone, iPad oder einen Mac verloren haben, entfernen Sie es zuerst aus Ihrer Apple-ID. Sonst erhält es den neuen Schlüssel ebenfalls.
- Melden Sie das verlorene Gerät unter **Einstellungen → Konto → Angemeldete Geräte** ab. WitnessWork bietet dann an, Ihren Schlüssel zu ändern.

## Den Schlüssel auf Ihrem Smartphone ändern

1. Öffnen Sie **Einstellungen → Konto → Kontoschlüssel ändern**. Sie brauchen das Internet.
2. Lesen Sie, was passieren wird, und tippen Sie dann auf **Schlüssel ändern**. Bestätigen Sie mit Face ID, Touch ID, Ihrem Code oder Ihrer Bildschirmsperre.
3. Kopieren Sie den neuen Wiederherstellungsschlüssel in einen Passwortmanager oder drucken Sie ihn aus.
4. Schalten Sie **Ich habe meinen neuen Wiederherstellungsschlüssel gespeichert** ein und tippen Sie dann auf **Schlüssel ändern**.
5. Lassen Sie WitnessWork geöffnet, bis **Kontoschlüssel geändert** erscheint.

## In einem Browser ändern

- Der Browser muss mindestens einen Tag lang angemeldet gewesen sein. Wenn nicht, sagt WitnessWork, ab wann es geht, oder Sie ändern ihn auf Ihrem Smartphone.
- Ihr Konto braucht einen Passkey. Der Browser bittet Sie, damit zu bestätigen. Wenn Sie keinen haben, fügen Sie auf Ihrem Smartphone einen hinzu oder ändern Sie den Schlüssel dort.

## Was dann passiert

- **Ihre anderen Geräte werden abgemeldet.** Ihre Aufzeichnungen bleiben auf ihnen. Melden Sie jedes Gerät mit dem neuen Wiederherstellungsschlüssel wieder an (**Einstellungen → Konto → Wiederherstellungsschlüssel verwenden**) oder mit einem QR-Code von einem angemeldeten Smartphone (**Mit QR-Code anmelden**).
- **Apple-Geräte** mit derselben Apple-ID erhalten den neuen Schlüssel und melden sich von selbst wieder an.
- **Ältere Versionen von WitnessWork** können sich erst wieder anmelden, wenn sie aktualisiert sind. WitnessWork listet solche, die es findet, vor dem Start auf. Aktualisieren Sie sie zuerst.
- **Ihre Buddies** erhalten eine Einladung, sich wieder zu verbinden.
- **Passkeys** funktionieren weiterhin für die Anmeldung im Web.
- **Die Kontoaktivität** zeigt **Kontoschlüssel geändert**.

## Wenn etwas schiefgeht

- **Es hat auf halbem Weg aufgehört:** Öffnen Sie WitnessWork erneut. **Einstellungen → Konto** zeigt **Änderung des Kontoschlüssels nicht abgeschlossen**. Tippen Sie auf **Weitermachen**, um sie abzuschließen, oder auf **Neuen Schlüssel verwerfen**, um Ihren aktuellen Schlüssel zu behalten.
- **Es heißt, der Schlüssel wurde auf einem anderen Gerät geändert:** Melden Sie sich mit dem neuen Wiederherstellungsschlüssel dieses Geräts an.
- **Ein alter Wiederherstellungsschlüssel funktioniert nicht:** Das ist nach einer Änderung zu erwarten.

## Gut zu wissen

- Niemand kann eine Änderung rückgängig machen oder einen alten Schlüssel zurückbringen, auch nicht der Support von WitnessWork.
- Wer Ihren Wiederherstellungsschlüssel hat, hat Ihr Konto. Bewahren Sie den neuen an einem Ort auf, an den nur Sie kommen.
- Sie haben alle Geräte und Ihren Schlüssel verloren? Siehe [Was ist, wenn ich den Zugang zu meinem WitnessWork-Konto verliere?](/help/account/lost-access).
