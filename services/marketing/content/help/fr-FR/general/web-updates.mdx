---
id: webUpdates
title: Comment obtenir la dernière version de WitnessWork sur le web ?
---

Il n’y a rien à télécharger. Quand une nouvelle version est prête, WitnessWork sur le web affiche **Mise à jour disponible** avec un bouton **Recharger**.

## Obtenir la nouvelle version

1. Choisissez **Recharger**.
2. Si vous avez installé l’application web, fermez-la et rouvrez-la.

## Bon à savoir

- WitnessWork ne se recharge jamais tout seul pendant que vous travaillez. Si vous attendez, le message revient quand vous retournez sur l’onglet.
- Un onglet laissé ouvert longtemps peut se recharger une fois tout seul.
- Recharger n’efface pas vos enregistrements. Tout ce qui n’était pas encore synchronisé se synchronise ensuite.

## En cas de problème

- **Il indique Mise à jour requise :** rechargez la page. Si cela n’aide pas, fermez l’onglet, rouvrez app.witnesswork.app et vérifiez votre connexion.
