id: accountHandoff
title: Comment passer à un nouveau téléphone ou passer d’un iPhone à Android ?
---

Affichez un code sur votre ancien téléphone et scannez-le avec le nouveau. Cela fonctionne entre deux téléphones quelconques, y compris d’un iPhone à Android et inversement. Un navigateur ne peut pas configurer un autre appareil.

## Passer à un nouveau téléphone

1. Sur l’ancien téléphone, allez à **Paramètres → Compte → Configurer un autre appareil**. Un code QR apparaît.
2. Sur le nouveau téléphone, installez WitnessWork.
3. Pendant la configuration, touchez **J’utilise déjà WitnessWork**, puis **Depuis votre autre téléphone**. Après la configuration, utilisez **Se connecter avec un code QR** dans **Paramètres → Compte**.
4. Scannez le code QR.
5. Vérifiez que les deux téléphones affichent le même code à six chiffres.
6. Sur l’ancien téléphone, touchez **Autoriser**, puis confirmez avec Face ID, votre empreinte, votre code ou le verrouillage de votre écran.

Votre compte et vos compagnons passent au nouveau téléphone. Votre ancien téléphone reste connecté.

## Récupérer aussi vos enregistrements

Vos enregistrements de service, vos contacts et vos notes ne font pas partie de cette étape. Une nouvelle installation démarre avec Cloud Sync activé, ils arrivent donc tout seuls une fois que vous êtes connecté. Ou activez d’abord **Sauvegarde** dans **Paramètres → Compte** sur l’ancien téléphone, et le nouveau téléphone propose de la restaurer. Vous pouvez aussi utiliser un fichier depuis **Paramètres → Sauvegarde et restauration**.

## Bon à savoir

- Les deux téléphones ont besoin d’internet, et le code dure 10 minutes.
- Si le nouveau téléphone utilisait les Compagnons avec un autre compte, il demande avant de le remplacer.
- Une clé d’accès peut faire cela sans votre ancien téléphone. Voir [Qu’est-ce qu’une clé d’accès ?](/help/account/passkeys-overview).
- Le code ne fonctionne pas ? Voir [Que faire si la connexion avec un code QR ne fonctionne pas ?](/help/account/account-handoff-trouble).
