title: Wie installiere ich WitnessWork auf meinem Home-Bildschirm oder Desktop?
---

Sie können WitnessWork in einem Browser-Tab nutzen oder es installieren, damit es wie eine App in einem eigenen Fenster öffnet. Es ist in beiden Fällen dieselbe App.

## Installieren

- **Chrome oder Edge auf einem Computer:** Öffnen Sie app.witnesswork.app und nutzen Sie das Installationssymbol in der Adressleiste oder den Eintrag **Installieren** im Menü.
- **Safari auf einem Mac:** Öffnen Sie das Menü **Ablage** und wählen Sie **Zum Dock hinzufügen**.
- **iPhone oder iPad:** Tippen Sie in Safari auf **Teilen** und dann auf **Zum Home-Bildschirm**.
- **Android:** Tippen Sie in Chrome oben im Banner **App installieren** auf **Installieren** und bestätigen Sie. Oder nutzen Sie das Browsermenü und wählen Sie **App installieren** oder **Zum Startbildschirm hinzufügen**.

## Gut zu wissen

- Eine Web-App auf dem Home-Bildschirm eines iPhone behält ihre Daten auch dann, wenn Sie sie eine Weile nicht öffnen. Siehe [Was speichert WitnessWork in meinem Browser?](/help/general/web-storage).
- Auf iPhone und iPad zeigt Safari stattdessen das Apple-Banner für die App aus dem App Store.
- Schließen Sie das Banner **App installieren** mit seinem X. Es bleibt in diesem Browser geschlossen, bis seine Websitedaten gelöscht werden oder Sie sich abmelden.
- Auf einem Computer oder wenn WitnessWork schon installiert ist, erscheint kein Banner.
