id: editRecurringPlan
title: Puis-je modifier ou supprimer une seule occurrence d’un plan récurrent ?
---

Oui. Dans l’onglet Calendrier, touchez le jour, puis touchez le plan pour l’ouvrir. Pour ne modifier que cette date, touchez Modifier (le crayon), faites vos changements, enregistrez, puis choisissez Seulement cette date. Modifier le Type, le titre ou le lieu pour une seule date fait de cette date un plan ponctuel à part. Pour ne supprimer que cette date, touchez Plus (•••), puis Supprimer → Supprimer ce plan. Votre plan récurrent reste intact pour tous les autres jours.
