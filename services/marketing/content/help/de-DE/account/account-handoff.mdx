id: accountHandoff
title: Wie wechsle ich auf ein neues Smartphone oder zwischen iPhone und Android?
---

Zeigen Sie auf Ihrem alten Smartphone einen Code und scannen Sie ihn mit dem neuen. Das funktioniert zwischen zwei beliebigen Smartphones, auch von iPhone zu Android und zurück. Ein Browser kann kein weiteres Gerät einrichten.

## Auf ein neues Smartphone wechseln

1. Gehen Sie auf dem alten Smartphone zu **Einstellungen → Konto → Weiteres Gerät einrichten**. Ein QR-Code erscheint.
2. Installieren Sie WitnessWork auf dem neuen Smartphone.
3. Tippen Sie bei der Einrichtung auf **Ich benutze bereits WitnessWork** und dann auf **Von Ihrem anderen Smartphone**. Nach der Einrichtung nutzen Sie **Mit QR-Code anmelden** unter **Einstellungen → Konto**.
4. Scannen Sie den QR-Code.
5. Prüfen Sie, ob beide Smartphones denselben sechsstelligen Code zeigen.
6. Tippen Sie auf dem alten Smartphone auf **Erlauben** und bestätigen Sie dann mit Face ID, Ihrem Fingerabdruck, Ihrem Code oder Ihrer Bildschirmsperre.

Ihr Konto und Ihre Buddies wechseln auf das neue Smartphone. Ihr altes Smartphone bleibt angemeldet.

## Auch Ihre Aufzeichnungen mitnehmen

Ihre Dienstaufzeichnungen, Kontakte und Notizen gehören nicht zu diesem Schritt. Eine neue Installation beginnt mit eingeschaltetem Cloud Sync, sodass sie von selbst ankommen, sobald Sie angemeldet sind. Oder schalten Sie zuerst auf dem alten Smartphone unter **Einstellungen → Konto** die **Sicherung** ein, dann bietet das neue Smartphone an, sie wiederherzustellen. Sie können auch eine Datei aus **Einstellungen → Sichern und Wiederherstellen** nutzen.

## Gut zu wissen

- Beide Smartphones brauchen das Internet, und der Code gilt 10 Minuten.
- Wenn das neue Smartphone Buddies mit einem anderen Konto genutzt hat, fragt es, bevor es das ersetzt.
- Ein Passkey kann das auch ohne Ihr altes Smartphone. Siehe [Was ist ein Passkey?](/help/account/passkeys-overview).
- Der Code funktioniert nicht? Siehe [Was ist, wenn die Anmeldung mit einem QR-Code nicht funktioniert?](/help/account/account-handoff-trouble).
