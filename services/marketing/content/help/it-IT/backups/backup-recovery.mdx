---
id: backupRecovery
title: Il mio backup sembra illeggibile o le registrazioni ripristinate mancano. Cosa devo fare?
---

Un file di backup è fatto per essere letto da WitnessWork, quindi non somiglia a un rapporto se lo apri. Conserva il file originale così com'è e ripristinalo da **Impostazioni → Backup e ripristino → Ripristina da backup**.

## Se dopo un ripristino mancano delle registrazioni

1. Conserva il file di backup originale. Non modificarlo né rinominarlo.
2. Fai un nuovo backup di ciò che c'è ora sul telefono: **Impostazioni → Backup e ripristino → Crea backup**.
3. Scrivi all'assistenza indicando la versione di WitnessWork e cosa è successo. Invia ogni file in privato.

## Da sapere

- I file di backup possono contenere dati dei contatti e appunti. Non metterli in segnalazioni pubbliche.
