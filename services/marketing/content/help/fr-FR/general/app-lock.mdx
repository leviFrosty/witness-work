---
id: appLock
title: Comment verrouiller WitnessWork avec mon visage, mon empreinte, mon code ou une clé d’accès ?
---

Vous pouvez demander à WitnessWork de vérifier votre visage, votre empreinte ou votre code à chaque ouverture.

## Activer le verrouillage

1. Ouvrez **Paramètres → Confidentialité**.
2. Activez **Exiger Face ID**. Sur d’autres téléphones, il indique **Exiger Touch ID**, **Exiger le code** ou, sur Android, **Exiger le déverrouillage biométrique**.
3. Confirmez que c’est bien vous.
4. Sous **Exiger**, choisissez au bout de combien de temps WitnessWork redemande après que vous l’avez quitté : tout de suite, ou après 1, 5 ou 15 minutes.

## Le désactiver

Ouvrez **Paramètres → Confidentialité**, désactivez le commutateur et confirmez que c’est bien vous.

## Bon à savoir

- Si votre visage ou votre empreinte n’est pas reconnu, utilisez le code, le code PIN, le schéma ou le mot de passe de votre téléphone.
- Le verrouillage ne s’applique qu’au téléphone où vous l’activez. Activez-le séparément sur chaque appareil.
- Votre téléphone doit avoir un code ou un verrouillage d’écran. S’il n’en a pas, touchez **Ouvrir les réglages** quand WitnessWork vous le demande, configurez-en un, puis réactivez le verrouillage.
- Quand le verrouillage est activé, le sélecteur d’apps affiche une carte vide. Sur Android, cela demande Android 13 ou une version plus récente.
- Le verrouillage ne couvre que l’application. Les widgets, les notifications, Siri et votre montre affichent toujours ce qu’ils affichent d’habitude.
- Si vous touchez un rappel ou un lien pendant que WitnessWork est verrouillé, il s’ouvre après le déverrouillage.

## Sur le web

Le verrouillage sur le web utilise une clé d’accès, votre compte doit donc en avoir une d’abord. Voir [Qu’est-ce qu’une clé d’accès ?](/help/account/passkeys-overview).

1. Ouvrez **Paramètres → Confidentialité**.
2. Activez **Exiger une clé d’accès** et confirmez avec votre clé d’accès. Vous devez être en ligne.
3. Sous **Exiger**, choisissez 1, 5 ou 15 minutes. Le web n’a pas d’option « tout de suite ».

Pour déverrouiller, cliquez sur **Déverrouiller avec une clé d’accès**. Pour désactiver le verrouillage, désactivez le commutateur et utilisez de nouveau votre clé d’accès.

- Le verrouillage ne vaut que pour ce navigateur. Se déconnecter le désactive.
- Il masque WitnessWork jusqu’au déverrouillage, mais il ne vous déconnecte pas. Sur un ordinateur partagé, déconnectez-vous quand vous avez terminé.
- Si vous retirez de votre compte toutes les clés d’accès qu’il utilise, le verrouillage se désactive tout seul.

## En cas de problème

- **Le déverrouillage échoue sans cesse sur votre téléphone :** vérifiez que votre code fonctionne sur l’écran de verrouillage du téléphone, puis fermez complètement WitnessWork et rouvrez-le.
- **Aucune de vos clés d’accès n’est disponible sur le web :** choisissez **Se déconnecter** sur l’écran de verrouillage et reconnectez-vous. Tout ce que ce navigateur n’avait pas synchronisé est effacé.
- **Toujours bloqué :** utilisez le lien d’assistance privé du centre d’aide, et ne mettez pas de détails personnels dans les rapports publics.
