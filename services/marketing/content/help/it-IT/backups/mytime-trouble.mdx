id: mytimeTrouble
title: Importazione da MyTime dice che il file non è un database. Cosa devo usare?
---

Importazione da MyTime richiede un backup .mytimedb originale creato da MyTime. Un PDF, un’esportazione di testo, un backup JSON di WitnessWork o un file rinominato in .mytimedb non funzionerà. Salva sul dispositivo una copia completa del backup di MyTime e selezionala tramite Impostazioni → Importazione da MyTime. Mantieni invariato il file originale. Se un backup valido continua a non funzionare, scrivi all’assistenza in privato indicando l’errore e la versione dell’app; non pubblicare il backup in una segnalazione pubblica.
