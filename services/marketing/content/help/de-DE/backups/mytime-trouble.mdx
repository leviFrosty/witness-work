id: mytimeTrouble
title: Der MyTime-Import sagt, die Datei sei keine Datenbank. Was soll ich verwenden?
---

Der MyTime-Import benötigt eine originale .mytimedb-Sicherung, die von MyTime erstellt wurde. Ein PDF, ein Textexport, eine WitnessWork-JSON-Sicherung oder eine in .mytimedb umbenannte Datei funktionieren nicht. Speichern Sie eine vollständige Kopie der MyTime-Sicherung auf Ihrem Gerät und wählen Sie sie über „Einstellungen“ → „MyTime-Import“ aus. Lassen Sie die Originaldatei unverändert. Schlägt eine gültige Sicherung trotzdem fehl, schreiben Sie dem Support privat eine E-Mail mit der Fehlermeldung und der App-Version; veröffentlichen Sie die Sicherung nicht in einem öffentlichen Issue.
