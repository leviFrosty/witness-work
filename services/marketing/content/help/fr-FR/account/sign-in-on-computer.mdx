title: Comment me connecter sur un ordinateur avec mon téléphone ?
---

Affichez un code QR dans le navigateur et approuvez-le depuis votre téléphone. Vous avez besoin de WitnessWork sur un iPhone ou un téléphone Android connecté à votre compte, et d’internet sur les deux appareils.

## Se connecter sur un ordinateur

1. Sur l’ordinateur, ouvrez app.witnesswork.app et choisissez **Utiliser mon téléphone**. Un code QR apparaît.
2. Sur votre téléphone, ouvrez **Paramètres → Compte → Se connecter sur un ordinateur**.
3. Scannez le code dans WitnessWork. L’application appareil photo ne l’ouvrira pas.
4. Vérifiez que le code à six chiffres sur votre téléphone correspond à celui du navigateur.
5. Touchez **Autoriser**, puis confirmez avec Face ID, votre empreinte ou votre code.

Votre téléphone affiche **Approuvé**. Le navigateur se connecte et propose d’ajouter une clé d’accès pour que la prochaine fois vous puissiez vous passer du téléphone.

## Bon à savoir

- N’approuvez qu’un ordinateur qui est devant vous. Si le téléphone avertit que le navigateur semble loin, continuez seulement si c’est votre propre ordinateur.
- Si ce n’est pas vous qui avez commencé, touchez **Ne pas autoriser**.
- Seul un téléphone peut approuver un navigateur. Sans votre téléphone, utilisez une clé d’accès ou votre clé de récupération. Voir [Que faire si je perds l’accès à mon compte WitnessWork ?](/help/account/lost-access).
- Un navigateur indique qu’il a été approuvé par un téléphone qui n’est pas le vôtre : choisissez **Ce n’était pas moi**. Voir [Que faire si mon téléphone ou mon ordinateur est perdu ou volé ?](/help/account/lost-device).

## En cas de problème

- **Le téléphone ne peut pas scanner :** dans les réglages de votre téléphone, autorisez WitnessWork à utiliser l’appareil photo.
- **Le code ne vient pas de WitnessWork, ou il est pour un autre téléphone :** sur l’ordinateur, ouvrez de nouveau app.witnesswork.app et choisissez **Utiliser mon téléphone**.
- **Le code a expiré :** les codes changent environ toutes les minutes et ne fonctionnent qu’une fois. Choisissez **Afficher un nouveau code** dans le navigateur.
- **Le téléphone indique qu’il ne peut pas vérifier cet appareil :** il ne peut pas approuver un ordinateur. Utilisez plutôt une clé d’accès ou votre clé de récupération.
