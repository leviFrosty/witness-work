title: Для чего используются пожертвования?
---

Ваше пожертвование помогает поддерживать работу этого приложения! Есть затраты на покупку реальных устройств в качестве оборудования для разработки, оплату услуг API по локации, сборы за API для построек, сборы за магазины приложений и альтернативные расходы многих часов, потраченных на разработку этого приложения. Любая поддержка очень ценна!
