title: Kann ich einem Kontakt ein Foto hinzufügen?
---

Ja. Öffnen Sie einen Kontakt, tippen Sie auf das Bild und wählen Sie ein Foto aus Ihrer Mediathek oder nehmen Sie ein neues auf. Das hilft, wenn Kontakte gleiche Namen haben, oder um die richtige Tür zu erkennen.

## Ein Foto hinzufügen

1. Öffnen Sie den Kontakt.
2. Tippen Sie auf das Bild.
3. Wählen Sie ein Foto oder nehmen Sie ein neues auf.

## Fotos auf Ihren anderen Geräten

- **Cloud Sync:** Kontaktfotos und Ihr Profilfoto werden zwischen Ihren Smartphones von selbst synchronisiert, innerhalb der 2 GB Fotospeicher Ihres Kontos. Siehe [Werden Fotos mit Cloud Sync synchronisiert?](/help/backups/cloud-sync-photos). Wenn Sie ein Foto ersetzen oder entfernen, wird sein Platz sofort frei.
- **iCloud (auf Android Google Drive):** Schalten Sie unter **Einstellungen → Sync** die Option **Bilder in die Synchronisierung einbeziehen** ein.
- **Im Web:** Fotos werden noch nicht synchronisiert. Sie können dort keines hinzufügen, und Kontakte zeigen ihre Initialen. Wenn Sie einen Kontakt im Web bearbeiten, bleibt sein Foto auf Ihren Smartphones unverändert.

Wenn ein Foto auf einem anderen Gerät fehlt, siehe [Warum fehlen Kontaktfotos auf meinem anderen Gerät?](/help/backups/sync-photos). Aktualisieren Sie WitnessWork auch auf diesem Gerät.
