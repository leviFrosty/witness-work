title: Wie sichere und stelle ich meine Daten wieder her?
---

Speichern Sie unter **Einstellungen → Sichern und Wiederherstellen** eine Sicherungsdatei und stellen Sie sie am selben Ort wieder her. Die Datei funktioniert auf iPhone, Android und im Web. Sie können damit Ihre Einträge also auch von einem Gerät auf ein anderes mitnehmen.

Für eine automatische Sicherung lesen Sie stattdessen [Was ist die WitnessWork-Sicherung?](/help/backups/account-backup).

## Sicherungsdatei erstellen

1. Öffnen Sie **Einstellungen → Sichern und Wiederherstellen**.
2. Tippen Sie auf **Ein Backup erstellen**.
3. Wählen Sie, wie die Datei geschützt werden soll. **Mein Konto** öffnet sie auf Ihren Geräten, die bei Ihrem Konto angemeldet sind, oder überall mit Ihrem Wiederherstellungsschlüssel. **Passwort** (mindestens 8 Zeichen) öffnet sie auf jedem Gerät mit diesem Passwort. Wählen Sie das, wenn Sie eine Kopie weitergeben möchten.
4. Speichern Sie die Datei mit dem Namen witness-work-backup.json.

Im Web wird die Datei in den Download-Ordner Ihres Browsers geladen.

## Aus einer Sicherungsdatei wiederherstellen

1. Öffnen Sie **Einstellungen → Sichern und Wiederherstellen**.
2. Tippen Sie auf **Von der Sicherung wiederherstellen**.
3. Wählen Sie Ihre Sicherungsdatei. Geben Sie ihr Passwort ein, falls sie eines hat.

Auf einem neuen Smartphone können Sie stattdessen beim Start der Einrichtung auf **Ich benutze bereits WitnessWork** tippen und dann auf dem Bildschirm **Willkommen zurück** unter **Andere Wege zur Wiederherstellung** die Option **Aus einer Sicherungsdatei** wählen.

## Gut zu wissen

- Beim Wiederherstellen werden die Einträge auf diesem Gerät, die in der Sicherung enthalten sind, ersetzt. Speichern Sie vorher eine aktuelle Sicherung.
- Die Datei enthält Dienstaufzeichnungen, Pläne, Kontakte, Besuche, Kategorien, Fahrtkilometer, Ihr Haustier, Ihr Profil und gemeinsame Einstellungen. Nicht enthalten sind Fotos, gemeinsame Autos und die eigenen Einstellungen dieses Geräts.
- Niemand kann eine geschützte Datei ohne ihr Passwort oder Ihr Konto öffnen, und WitnessWork kann ein vergessenes Passwort nicht wiederherstellen.
- Eine Sicherung, die mit einer neueren Version von WitnessWork erstellt wurde, lässt sich erst nach einem Update wiederherstellen.
- Halten Sie die Datei und ihr Passwort privat. Sie kann Angaben zu Wohnungsinhabern enthalten.

## Wenn etwas schiefgeht

- **Es heißt, Sie sollen sich zuerst anmelden:** Melden Sie sich auf diesem Smartphone mit **Mit QR-Code anmelden** oder Ihrem Wiederherstellungsschlüssel bei Ihrem Konto an und versuchen Sie es dann erneut.
- **Es heißt, die Datei gehört zu einem anderen Konto:** Stellen Sie sie auf einem Gerät wieder her, das bei diesem Konto angemeldet ist, oder erstellen Sie dort eine passwortgeschützte Sicherung.
- **Einige Einträge konnten nicht gelesen werden:** Der Rest wird wiederhergestellt, und WitnessWork sagt Ihnen, wie viele ausgelassen wurden.
- **Es klappt immer noch nicht:** Nutzen Sie die private Support-Option im Hilfecenter.
