id: editRecurringPlan
title: Kann ich einen einzelnen Tag eines wiederkehrenden Plans bearbeiten oder löschen?
---

Ja. Sie können einen Tag ändern oder entfernen, ohne den Rest Ihres wiederkehrenden Plans anzutasten. Er läuft an allen anderen Tagen weiter.

## Einen Tag überspringen

1. Öffnen Sie den Tab **Zeitplan** und tippen Sie auf den Tag.
2. Tippen Sie auf den Plan, um ihn zu öffnen.
3. Tippen Sie auf **Mehr (•••)**, dann auf **Löschen** und dann auf **Diesen Plan löschen**.

Wenn der Tag mehr als einen Plan hat, tun Sie das für jeden.

## Einen Tag ändern

1. Öffnen Sie den Tab **Zeitplan**, tippen Sie auf den Tag und tippen Sie auf den Plan.
2. Tippen Sie auf **Bearbeiten** (der Stift) und nehmen Sie Ihre Änderungen vor.
3. Speichern Sie und wählen Sie **Nur dieses Datum**.

## Gut zu wissen

- Wenn Sie für einen Tag den Typ, den Titel, den Ort oder die Erinnerung **Benachrichtige mich** ändern, wird dieser Tag zu einem eigenen einmaligen Plan.
