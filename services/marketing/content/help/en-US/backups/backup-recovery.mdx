title: My backup looks unreadable or my restored records are missing. What should I do?
category: backups
related:
  - 433
---

A WitnessWork backup is structured JSON for the app to read, so it does not look like a printable Service Report. Keep the original file unchanged and restore it through Settings → Backup & Restore → Restore From Backup. If records are missing, preserve the original backup and create a separate backup of the device's current data before trying another restore. Email support with the app version and what happened; arrange any file sharing privately. Backup files can contain contact details and notes, so keep them out of public bug reports.
