id: webInstall
title: How do I install WitnessWork on my home screen or desktop?
category: general
platforms: [web]
---

You can use WitnessWork in a browser tab, or install it so it opens in its own window like an app. It's the same app either way.

- **Chrome or Edge on a computer:** open app.witnesswork.app and use the browser's install option (an icon in the address bar, or the menu's Install entry).
- **Safari on a Mac:** open the File menu and choose Add to Dock.
- **iPhone or iPad:** in Safari, tap Share, then Add to Home Screen. A web app on the Home Screen keeps its data even when you don't open it for a while (see [What does WitnessWork keep in my browser?](/help/general/web-storage)).
- **Android:** in Chrome on a phone, WitnessWork shows an Install App banner at the top of the page. Tap Install, then confirm in the browser's prompt, and WitnessWork is added to your home screen. You can also use the browser's menu: Install app or Add to Home Screen.

On an iPhone or iPad, Safari shows Apple's own banner for the WitnessWork app in the App Store instead. You can dismiss WitnessWork's Install App banner with its X, and it stays dismissed in this browser until its site data is erased or you sign out. There's no banner on a computer, and none once WitnessWork is installed.
