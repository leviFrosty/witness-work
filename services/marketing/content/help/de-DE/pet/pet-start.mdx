id: petStart
title: Wie bekomme ich ein Haustier, und wie schalte ich es aus?
---

Der Haustier-Begleiter ist freiwillig. Sie adoptieren einen auf dem **Startbildschirm**, und Sie können ihn jederzeit ausblenden.

## Ein Haustier adoptieren

1. Suchen Sie auf dem Startbildschirm die Karte **Lernen Sie Ihren Begleiter kennen**.
2. Tippen Sie auf **Haustier wählen**.
3. Wählen Sie ein Löwenjunges, einen Welpen, ein Kätzchen, einen Esel oder ein Lamm.
4. Geben Sie einen Namen ein, wenn Sie möchten.
5. Tippen Sie auf **Adoptieren**.

Eine kurze Einführung zeigt dann, wie sich Herzen füllen, wie Sie beim Unterwegssein Münzen für Hüte und Zimmergegenstände verdienen und wie Sie einrichten. Tippen Sie auf **Weiter** oder schließen Sie sie, um sie zu überspringen. Sie haben jeweils einen Begleiter.

## Das Angebot zurückholen

Wenn Sie **Nicht jetzt** gewählt haben, halten Sie eine leere Stelle auf dem Startbildschirm gedrückt, tippen Sie auf **Bereiche hinzufügen** und dann auf **Haustier**. Oder schalten Sie **Haustier** unter **Einstellungen → Präferenzen → Startbildschirm** ein.

## Ihr Haustier ausblenden

- Halten Sie die Karte des Haustiers gedrückt, wählen Sie **Startbildschirm bearbeiten** und tippen Sie auf das graue Minus darauf.
- Oder schalten Sie in den Einstellungen Ihres Haustiers (die Einstellungstaste oben rechts in seinen Details) **Auf Home anzeigen** aus.
- Oder schalten Sie **Haustier** unter **Einstellungen → Präferenzen → Startbildschirm** aus.

Beim Ausblenden bleiben Ihr Haustier, sein Zimmer und seine Andenken erhalten. Schalten Sie **Haustier** wieder ein, und alles kommt zurück.
