title: 我要如何在 iPad 上使用鍵盤快速鍵切換畫面？
---

將實體鍵盤連接到執行 iPadOS 26 或更新版本的 iPad，然後在主要導覽可見時按住 Command（指令）鍵。底部分頁或側邊欄項目旁會出現小小的快速鍵標籤。按下 Command 和顯示的數字即可開啟該畫面；放開 Command 就會隱藏標籤。數字依照目前可見的導覽順序排列，因此預設情況下，首頁是 Command 1，聯絡人是 Command 2。其他數字取決於哪些項目可見，包括側邊欄中的設定。使用這些導覽快速鍵之前，請先關閉任何開啟中的表單或其他畫面；它們不會儲存或捨棄紀錄。我們只會統計是否使用了快速鍵，不會記錄你輸入的內容。需要安裝包含鍵盤功能的 App 版本，且 iPhone 和 Android 不提供此功能。如果沒有出現標籤，請確認鍵盤已連接、回到主要導覽畫面，並更新後重新開啟 App。你隨時都可以改用點按導覽項目。若有其他問題，請使用幫助中心的私人支援連結，並避免在公開回報中留下聯絡資料。
