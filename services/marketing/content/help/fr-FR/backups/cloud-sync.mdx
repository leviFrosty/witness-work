id: cloudSync
title: Qu’est-ce que Cloud Sync ?
---

Cloud Sync garde vos enregistrements identiques sur tous vos appareils : iPhone, Android et web. Il fonctionne entre un iPhone et un téléphone Android, et il est gratuit. Vous seul pouvez lire vos enregistrements.

Une nouvelle installation démarre avec Cloud Sync activé. Voir [Cloud Sync est-il activé par défaut ?](/help/backups/cloud-sync-default).

## Voir ou changer votre synchronisation

1. Ouvrez **Paramètres → Synchronisation**.
2. Voyez quelle option cet appareil utilise, ou choisissez Cloud Sync, iCloud (Google Drive sur Android) ou Désactivée.

## Bon à savoir

- Vos appareils ne se synchronisent qu’avec les appareils qui utilisent la même option. Choisissez donc la même sur chacun. Les changements arrivent généralement en quelques secondes pendant que l’application est ouverte.
- Votre photo de profil, les photos de contacts et les photos dans les notes se synchronisent aussi. Voir [Les photos se synchronisent-elles avec Cloud Sync ?](/help/backups/cloud-sync-photos).
- Le web ne fonctionne qu’avec Cloud Sync. Si votre téléphone utilise autre chose, le web demande de l’activer. Voir [Pourquoi mon téléphone est-il passé à Cloud Sync ?](/help/backups/cloud-sync-from-web).
- Un nouveau téléphone que vous configurez avec le code QR ou la clé de récupération de votre compte reçoit vos enregistrements par Cloud Sync. Vous n’avez pas besoin de restaurer.
- Si votre sauvegarde la plus récente est plus récente que vos copies Cloud Sync, le nouveau téléphone propose aussi de la restaurer.
- Mettez WitnessWork à jour s’il demande l’accès Supporter pour utiliser Cloud Sync.

## En cas de problème

- **Paramètres → Synchronisation indique que Cloud Sync est en pause ou pas encore disponible :** vos changements restent sur cet appareil et se synchronisent dès que le service revient. Touchez **Sync maintenant** pour vérifier de nouveau.
