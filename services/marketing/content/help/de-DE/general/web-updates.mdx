---
id: webUpdates
title: Wie bekomme ich die neueste Version von WitnessWork im Web?
---

Es gibt nichts herunterzuladen. Wenn eine neue Version bereit ist, zeigt WitnessWork im Web **Update verfügbar** mit einer Taste **Neu laden**.

## Die neue Version holen

1. Wählen Sie **Neu laden**.
2. Wenn Sie die Web-App installiert haben, schließen Sie sie und öffnen Sie sie erneut.

## Gut zu wissen

- WitnessWork lädt nie von selbst neu, während Sie arbeiten. Wenn Sie warten, kommt die Meldung wieder, sobald Sie zum Tab zurückkehren.
- Ein Tab, der lange geöffnet bleibt, kann einmal von selbst neu laden.
- Das Neuladen löscht Ihre Aufzeichnungen nicht. Alles, was noch nicht abgeglichen war, wird danach abgeglichen.

## Wenn etwas schiefgeht

- **Es heißt „Update erforderlich“:** Laden Sie die Seite neu. Hilft das nicht, schließen Sie den Tab, öffnen Sie app.witnesswork.app erneut und prüfen Sie Ihre Verbindung.
