title: "Kuki ntasuzuma QR code y'ikarita, cyangwa kuki umurongo w'ikarita wanjye udakora?"
---

Reba ubutumwa ubona hasi. Niba code y'ikarita itasuzumwa, ushobora kwandika umurongo cyangwa gukoresha indi nzira y'ikarita.

## Gusuzuma QR code y'ikarita

Ibi bibonekera muri porogaramu za telefoni gusa. Kuri murandasi, manika umurongo ukoresheje **Andika umurongo w'ikarita**.

- **"WitnessWork ikeneye kamera kugira ngo isuzume QR code."** Kanda **Fungura Igenamiterere**, wemerere WitnessWork gukoresha kamera, hanyuma wongere ugerageze.
- **"Iyo QR code nta murongo wa murandasi ifite."** Code ifite ikindi kitari aderesi ya murandasi. Koresha **Shyira akadomo ku ikarita** cyangwa **Shushanya inkombe y'agace**, cyangwa ufate ifoto y'ikarita.
- **Nta kintu kibaye:** fata ikarita iringaniye kandi itanyeganyega ahari urumuri ruhagije, code yose igaragara. Kanda **Hagarika gusuzuma** kugira ngo wandike umurongo.

## Umurongo w'ikarita udakora

**Andika umurongo w'ikarita** ibika umurongo wose umanitse. Uwufungure ukoresheje buto ya **Ikarita** y'agace.

WitnessWork inagerageza gushyira akadomo ku hantu kugira ngo **Imiyoboro** ikore. Ibi bikora ku mirongo ya Google Maps, Apple Maps, cyangwa OpenStreetMap iri ahantu. Umurongo mugufi, nka maps.app.goo.gl, ukeneye murandasi mu gihe "Gushaka aho biri…" kigaragara.

Niba nta kadomo kagaragara, umurongo uracyafunguka. Kanda **Shyira akadomo ku ikarita** ukande aho agace kari. Akadomo washyizeho ubwawe ntigahindurwa n'umurongo.

## Gusuzuma inyandiko

Kuri iPhone na iPad, "Nta nyandiko zabonetse mu gusuzuma" bivuze ko wongera gusuzuma ahari urumuri rwiza ukoresheje urupapuro ruringaniye, cyangwa ukandika inyandiko. Kuri Android, koporora inyandiko ziri ku ifoto ukoresheje Google Lens, hanyuma uzimanike.
