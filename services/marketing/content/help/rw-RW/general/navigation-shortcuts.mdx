title: Nigenza nte kugira ngo ngendere ku mfunguzo z'ibyoroshyo kuri iPad?
---

Huza clavier ya iPad ikoresha iPadOS 26 cyangwa irenzeho, hanyuma ufate ku kintu cya Command mu gihe imiyoborere nyamukuru igaragara. Utwandiko duto tw'ibyoroshyo tugaragara iruhande rw'utubuto two hasi cyangwa ibintu byo kuri sidebar. Kanda Command n'umubare ugaragara kugira ngo ufungure iyo ecran; irekure Command kugira ngo utwandiko dutwikirwe. Imibare ikurikiza uko imiyoborere igaragara, bityo mu buryo busanzwe Ahabanza ni Command 1 naho Abantu ni Command 2. Indi mibare iterwa n'ibintu bigaragara, harimo Igenamiterere kuri sidebar. Funga fomu cyangwa indi ecran yose ifunguye mbere yo gukoresha ibi byoroshyo; ntibibika cyangwa ngo bitere kureka inyandiko. Ikoreshwa ry'ibyoroshyo ni ryo ribarwa gusa, si ibyo wandika. Bisaba porogaramu yashyizweho ifite ubushobozi bwa clavier kandi ntibiboneka kuri iPhone cyangwa Android. Niba utwandiko tutagaragara, reba ko clavier ihujwe, garuka ku miyoborere nyamukuru, ushyire porogaramu ku gihe maze uyifungure bundi bushya. Burigihe ushobora gukanda ibintu by'imiyoborere. Ku bindi bibazo, koresha aho ubufasha bwa bwite buri mu Kigo cy'ubufasha kandi ntushyire amakuru bwite mu bitekerezo rusange.
