title: Bushe ningalundako shani munyina, kabili ni nani ushininkisha ukupempa?
---

Isuleni Buddies ukufuma pa Ukupanga, nelyo mutinike Itaneni Banyina pa Ubupange ubupya ilyo mushakwata munyina, no kutinika Itaneni Munyina nelyo bati ya + pa kutuma Buddies Invite. Pa kutantika mu muntu, bomfyeni bati ya code pa kulanga Buddies Code yenu kabili umbi asikene muli WitnessWork. Kuti mwanamika na link ukupitila mu Bikeni Link ya Kwita. Uwapokelela atinika Sumina; uwapanga ukwita elyo asula Buddies → Ifyo Bapempa no kutinika Sumina. Mutendeka ukumona ubupange bwa bonse panuma ya kushininkisha fye. Shininkisheni fye uo mwafwaya ukwita.
