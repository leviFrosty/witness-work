title: Para que servem as doações?
---

Sua doação ajuda a manter este app funcionando! Existem custos em comprar dispositivos reais como equipamentos de desenvolvimento, pagar taxas de serviço de API de localização, taxas de API de build, taxas de loja de aplicativos e custo de oportunidade das muitas horas que passei desenvolvendo esse app. Cada apoio é muito apreciado!
