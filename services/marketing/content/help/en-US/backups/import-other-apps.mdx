You can import a MyTime backup. Other apps' files aren't supported, but you can paste readable text into Scribe AI.

## Import from MyTime

1. In MyTime, go to **More → Settings → Backup** and email yourself a backup.
2. Save the attached .mytimedb file on your device. On Android or the web, send it from MyTime on your iPhone and download the attachment on that device.
3. In WitnessWork, open **Settings → Import Data → From MyTime**. During setup, choose **From MyTime** instead.
4. Choose the file.
5. Review the preview, then import.

## Good to know

- On the web, the file stays in your browser and isn't uploaded. A file over 25 MB is refused.
- For another app, try exporting readable text and pasting it into Scribe AI. Check what it proposes before you save.
- WitnessWork backup files go in **Settings → Backup & Restore**, not here.
- To bring in data from Notes or paper later, use **Settings → Import Data**.

## If it says the file is not a database

Import needs the original .mytimedb file made by MyTime. A PDF, text export, WitnessWork backup, or a renamed file won't work. Keep the original file unchanged. If a valid backup still fails, email support privately with the error and your WitnessWork version. Don't post the backup publicly.
