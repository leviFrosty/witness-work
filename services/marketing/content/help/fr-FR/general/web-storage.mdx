id: webStorage
title: Que garde WitnessWork dans mon navigateur ?
---

WitnessWork sur le web garde vos enregistrements et votre connexion dans votre navigateur, pour s’ouvrir directement sur vos données et fonctionner hors ligne. Ils y restent jusqu’à votre déconnexion.

## Bon à savoir

- Se déconnecter efface vos enregistrements et votre connexion de ce navigateur. Vider les données du site aussi. Votre compte et vos enregistrements synchronisés ne sont pas perdus, tant que vous avez un moyen de vous reconnecter. Voir [Et si je perds l’accès ?](/help/account/lost-access).
- Il n’y a pas de verrouillage automatique. Toute personne qui peut utiliser ce navigateur peut y ouvrir WitnessWork. Sur un ordinateur partagé, déconnectez-vous quand vous avez terminé. Voir [Se déconnecter sur le web](/help/account/web-sign-out).
- WitnessWork fonctionne dans un seul onglet à la fois. Voir [Pourquoi WitnessWork indique-t-il qu’il est ouvert dans un autre onglet ?](/help/general/web-tabs).

## Safari

Safari efface les données d’un site après 7 jours sans visite. Une application web sur l’écran d’accueil d’un iPhone en est exemptée. Si cela arrive, reconnectez-vous, par exemple avec votre clé d’accès, et vos enregistrements synchronisés reviennent. Les changements qui n’étaient pas synchronisés sont perdus, gardez donc Cloud Sync activé et laissez-le finir.

## En cas de problème

- **Votre navigateur ne peut pas enregistrer :** WitnessWork continue de fonctionner et vous le dit une fois. Si vous manquez de place, libérez de l’espace sur votre appareil et gardez l’onglet ouvert. WitnessWork enregistre vos changements dès qu’il le peut.
- **Vous êtes dans une fenêtre privée :** certaines ne laissent les sites rien enregistrer. Les changements sont perdus quand vous fermez l’onglet, utilisez donc une fenêtre normale.
