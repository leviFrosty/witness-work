title: Comment ajouter un compagnon, et qui confirme la demande ?
---

Ouvrez Compagnons depuis Calendrier, ou touchez Inviter des compagnons sur un nouveau plan tant que vous n’avez pas encore de compagnon, puis touchez Inviter un compagnon ou le bouton + pour partager une invitation Compagnons. Pour vous associer en personne, utilisez le bouton de code pour afficher votre code Compagnons et demandez à l’autre personne de le scanner dans WitnessWork. Vous pouvez aussi coller un lien via Saisir le lien d’invitation. Le destinataire touche Accepter ; la personne qui a créé l’invitation ouvre alors Compagnons → Demandes et touche Confirmer. Vous ne commencez à voir les plans de l’autre qu’après cette confirmation. Ne confirmez que la personne que vous aviez l’intention d’inviter.
