id: debugTools
title: 디버깅 도구는 무엇을 하나요?
---

디버깅 도구는 지원팀과 문제를 해결하는 데 도움이 됩니다. 설정 → 고급에서 켜며, iOS와 Android 모두에서 켠 기기에만 적용됩니다. 진단, 테스트 데이터, 복구 작업이 있는 도구 탭을 추가하고, 일부 화면에 추가 기술 정보를 표시하며, 더 자세한 진단 로깅을 켭니다. 일부 도구 작업은 샘플 데이터를 추가하거나 데이터를 영구적으로 삭제하므로 지원팀이 요청할 때만 사용하고, 먼저 설정 → 백업 및 복원에서 백업하세요. 스위치를 켜거나 꺼도 데이터는 바뀌지 않으며, 끄면 도구 탭과 정보가 다시 숨겨집니다.
