title: Comment ajouter des photos à une note ?
---

Dans l’éditeur de note, touchez le bouton photo, puis **Prendre une photo** ou **Choisir des photos**. Une note peut contenir jusqu’à 10 photos.

Sur le web, vous pouvez aussi coller une image que vous avez copiée ou faire glisser un fichier image sur la note.

## Changer la taille d’une photo

1. Pendant que vous modifiez la note, touchez la photo.
2. Faites glisser un coin pour la rendre plus petite ou plus grande.

## Voir ou partager une photo

Touchez une photo dans une note pour la voir en plein écran ou la partager.

## Bon à savoir

- Les photos sont redimensionnées et enregistrées sur votre appareil.
- Sur le web, le texte que vous collez depuis une page garde ses mots mais pas ses images. Copiez l’image elle-même pour l’ajouter. Si le navigateur ne peut pas ouvrir un fichier, utilisez un JPEG ou un PNG.
- Un trajet sur une voiture partagée n’a pas de bouton photo. Sa note est partagée avec tous ceux de la voiture, mais pas les photos.
- Quand le mode protection des données est activé, les notes de visite ne peuvent pas contenir de photos, car la photo du domicile de quelqu’un est une information personnelle.
- Pour voir les photos sur vos autres appareils, y compris le web, utilisez Cloud Sync, qui les envoie de lui-même, ou activez **Inclure les images dans la synchronisation** pour iCloud (Google Drive sur Android). Voir [Pourquoi une photo manque-t-elle dans une note ?](/help/notes/notes-sync).
- Les fichiers de sauvegarde et les partages de contacts laissent les photos de côté.
- Un plan auquel vous invitez des compagnons partage aussi les photos de sa note. Un compagnon voit une image de remplacement jusqu’à la fin du téléchargement d’une photo. Les photos partagées sont supprimées un mois après le plan, ou tout de suite quand vous les retirez, supprimez le plan ou arrêtez de le partager.
