id: backupRestore
title: 데이터를 어떻게 백업하고 복원하나요?
---

iOS나 Android에서 JSON 백업을 내보내거나 복원하려면 설정 → 백업 및 복원 → 백업 생성 또는 백업에서 복원을 여세요. 새 기기에서는 설정 화면 “중단한 지점부터 다시 시작하세요”에서 ‘백업 파일에서’를 선택할 수도 있으며, 거기서 복원하면 복원된 프로필로 설정이 마무리됩니다. 백업에는 봉사 기록, 계획, 연락처, 방문, 카테고리, 프로필, 공유 환경설정이 포함됩니다. 복원하면 포함된 로컬 데이터가 대체되며, 오래된 백업에는 카테고리나 프로필이 없을 수 있는데 그런 항목은 그대로 유지됩니다. 기기 식별 정보, iCloud 또는 Google Drive 동기화 설정, 데이터 보호 모드, 분석 동의, 온보딩 진행 상황은 이 기기에 남습니다. 사진 파일은 JSON 백업에 포함되지 않습니다. iOS의 iCloud 사진은 사진 동기화를 따로 켜세요. 복원하기 전에 최신 백업을 저장하고 비공개 위치에 보관하세요. 집주인 정보가 포함될 수 있습니다. 복구 도움이 필요하면 도움말 센터의 비공개 지원 옵션을 이용하세요.
