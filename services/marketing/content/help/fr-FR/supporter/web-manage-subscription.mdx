title: Comment gérer ou annuler un abonnement acheté sur le web ?
---

Ouvrez votre page d’abonnement depuis WitnessWork sur le web ou depuis un e-mail de reçu. Vous pouvez y annuler, changer votre moyen de paiement et voir vos reçus.

## Ouvrir votre page d’abonnement

1. Dans WitnessWork sur le web, ouvrez **Paramètres → Gérer l’abonnement**.
2. Choisissez **Gérer**. Votre page d’abonnement s’ouvre dans un nouvel onglet.
3. Si elle demande votre e-mail, saisissez celui que vous avez utilisé au paiement.
4. Ouvrez le lien de connexion qu’elle vous envoie.

Chaque e-mail de reçu contient aussi un lien vers cette page, vous pouvez donc l’utiliser sans vous connecter à WitnessWork.

## Bon à savoir

- Annuler arrête le prochain renouvellement. Votre accès Supporter continue jusqu’à la fin de la période que vous avez payée.
- Un pourboire est ponctuel. Il n’y a rien à annuler, et vous ne serez pas facturé de nouveau.
- La pause n’est pas disponible pour les abonnements web. Vous pouvez annuler et vous réabonner quand vous voulez.
- L’application sur téléphone ne peut pas gérer un abonnement web. Utilisez le web, ou le lien de l’e-mail de votre reçu.
- Si vous avez acheté sur l’App Store ou Google Play, **Gérer** ouvre à la place la page d’abonnements de cette boutique.
- Si vous déménagez dans un pays où le web ne vend pas, les renouvellements et les changements de carte avec une carte ou une adresse de facturation de ce pays sont refusés. Abonnez-vous plutôt sur l’App Store ou Google Play.

## En cas de problème

- **Pas de lien de connexion :** vérifiez que vous avez saisi l’e-mail utilisé au paiement, et regardez dans vos courriers indésirables.
- **Pas de Gérer l’abonnement dans les Paramètres :** votre accès Supporter n’est pas un abonnement que vous pouvez modifier à cet endroit, par exemple une attribution gratuite.
- **Impossible de trouver votre abonnement :** écrivez à [support@witnesswork.app](mailto:support@witnesswork.app) depuis l’adresse utilisée au paiement.

Pour demander un remboursement, voir [Puis-je obtenir un remboursement pour un achat sur le web ?](/help/supporter/web-purchase-refund).
