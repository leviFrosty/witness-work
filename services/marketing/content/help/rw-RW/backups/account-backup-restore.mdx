title: "Nsubiza nte backup yanjye kuri telefoni nshya?"
---

Shyira WitnessWork kuri telefoni nshya, injire muri konti yawe, hanyuma ugarure backup yawe porogaramu igihe iyigusabye.

## Injira kuri telefoni nshya

Niba ugifite telefoni yawe ya kera:

1. Kuri telefoni ya kera, fungura **Igenamiterere → Konti → Shyiraho ikindi gikoresho**.
2. Kuri telefoni nshya, mu gihe cyo gutangira, kanda **Nari nsanzwe nkoresha WitnessWork**, hanyuma **Uvuye ku yindi telefoni yawe**.
3. Suzuma code yerekanwa kuri telefoni ya kera.

Niba utagifite telefoni ya kera, fungura **Igenamiterere → Konti → Koresha urufunguzo rwo kugarura** kuri telefoni nshya wandike urufunguzo rwawe.

## Garura backup yawe

1. Telefoni nshya igihe itanze backup yawe, kanda **Garura**.
2. Niba telefoni isanzwe ifite inyandiko, hitamo **Huriza hamwe** kugira ngo uzibike wongereho iz'iyo backup, cyangwa **Simbuza** kugira ngo ukoreshe iz'iyo backup gusa.
3. Fungura **Kora backup kuri WitnessWork** no kuri telefoni nshya.

Ushobora kandi kugarura nyuma ukoresheje **Igenamiterere → Konti → Garura muri backup**.

## Byiza kumenya

- Niba ibindi bikoresho byawe bikoresha [Cloud Sync](/help/backups/cloud-sync), inyandiko zawe zigerayo ubwo buryo.
- Niba ufite backup z'ibikoresho byinshi, kugarura birazihuriza hamwe.
- Backup yakozwe na WitnessWork nshya cyane irasigara kugeza uvuguruye. Porogaramu ikubwira iyo biriho.
