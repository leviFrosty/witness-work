id: shareApp
title: Comment partager WitnessWork avec un ami ?
---

Touchez votre photo de profil, puis Paramètres → Partager WitnessWork. Choisissez Android ou iPhone, et votre ami peut scanner le code avec l’appareil photo de son téléphone pour ouvrir WitnessWork dans Google Play ou l’App Store. Partager le lien envoie un message avec les deux liens de boutique, ce qui fonctionne pour tout le monde. WitnessWork est gratuit sur les deux. Le message ne contient que les liens de boutique, rien sur vous ni sur vos données. Si un code ne se scanne pas, augmentez la luminosité de votre écran ou utilisez plutôt Partager le lien.
