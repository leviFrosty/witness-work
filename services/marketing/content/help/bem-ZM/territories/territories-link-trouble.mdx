title: Mulandu nshi link ya territory ya mwenyi nelyo QR code tailasula, nelyo mulandu nshi ilanda ukuti yapwa?
---

Peji ilanda ico cibipa. Link ibomba ukufika inshita yaiko yapwa nelyo uwasabankanya ailepwisha.

## Ico peji ilanda

- **"This Link Has Expired":** inshita ya link yapwa. Pepeni imbi nga mucili mulebomba.
- **"This Link Has Ended":** uwasabankanya aipwishishe, abwelesha territory, nelyo atolele umusebo. Pepeni link impya.
- **"This Link Doesn't Work":** icipande ca link cabula. Ama app ya kutuma ubutumwa pa nshita imo yafumyapo ama link ayatali. Kopololeni link yonse, nelyo musande QR code.
- **"You're Offline":** tantikeni ku intaneti ukuti musule link. Pa numa ya kusula, ico mwalemba ukwabula intaneti citumwa ilyo mwabwela pa intaneti.
- **"Links Are Paused":** eseni nakabili pa numa ya mineti shinono.
- **"None of this link's streets can be recorded right now":** imisebo yapelwa nelyo yatolwa. Pusheni uwasabankanya link.
- **"1 change wasn't saved. That street isn't shared with this link anymore."** nelyo **"records from this browser weren't saved":** link yapwa foni yenu ishilatuma. Ambileni uwasabankanya link ifyo mwalembele.

## Ifyo mwafwile ukwishiba

- Sandeni QR code ne kamera ya foni yenu elyo mutinike link iyo ilanga.
- Browser yenu isunga ifyo mwalembele ukufika link ilepwa. Tinikeni **Lekeni Ukwibukila Link Iyi** ukuti mufifumyepo bwangu. Ifyo mwatumine kale fyashala ku kabungwe.

## Nga mwasabankanya link

Isuleni territory elyo mutale pe pi **Abo Mwasabankanya**. Link iyapwa nelyo iyaleka ilanga inshita. Ukupanga impya, tinikeni **Tumina**, elyo **Link nelyo QR Code**. Moneni [Nshani ukusabankanya territory na muntu ushakwata app?](/help/territories/territories-guest-link)
