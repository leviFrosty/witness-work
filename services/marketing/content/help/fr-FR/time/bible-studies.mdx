id: bibleStudies
title: Comment les cours bibliques sont-ils comptés ?
---

Les cours bibliques sont comptés par contact, pas par jour. Chaque contact avec qui vous étudiez compte pour 1 cours dans le mois, quel que soit le nombre de fois où vous vous rencontrez.

## Compter un cours

1. Ouvrez le contact.
2. Enregistrez une conversation.
3. Marquez-la **Réalisation d’une étude biblique**.

## Bon à savoir

- Pour augmenter votre nombre de cours, marquez un cours avec un autre contact.
- Un contact que quelqu’un a partagé avec vous est le sien, donc ses visites ne comptent pas pour vous. Dès que vous enregistrez votre propre cours avec ce contact, il compte.
