id: shareApp
title: Wie teile ich WitnessWork mit einem Freund?
---

Öffnen Sie **Einstellungen → WitnessWork teilen** und zeigen Sie Ihrem Freund einen Code oder senden Sie ihm einen Link. WitnessWork ist auf iPhone und Android kostenlos.

## Mit einem Code teilen

1. Tippen Sie auf Ihr Profilbild und dann auf **Einstellungen → WitnessWork teilen**.
2. Wählen Sie **Android** oder **iPhone**.
3. Ihr Freund scannt den Code mit der Kamera seines Smartphones, um WitnessWork bei Google Play oder im App Store zu öffnen.

## Mit einem Link teilen

Tippen Sie auf **Link teilen**. Die Nachricht enthält beide Store-Links und funktioniert deshalb für jeden.

## Gut zu wissen

- Die Nachricht enthält nur die Store-Links. Sie sagt nichts über Sie oder Ihre Aufzeichnungen.

## Wenn etwas schiefgeht

- **Ein Code lässt sich nicht scannen:** Erhöhen Sie die Helligkeit Ihres Bildschirms oder nutzen Sie stattdessen **Link teilen**.
