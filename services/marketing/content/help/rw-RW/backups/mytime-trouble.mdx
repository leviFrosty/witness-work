id: mytimeTrouble
title: MyTime Import ivuga ko dosiye atari database. Nakoresha iki?
---

MyTime Import ikenera backup y'umwimerere ya .mytimedb yakozwe na MyTime. PDF, inyandiko yoherejwe, backup ya JSON ya WitnessWork, cyangwa dosiye yahinduriwe izina ikitwa .mytimedb ntibizakora. Bika kopi yuzuye ya backup ya MyTime ku gikoresho cyawe uyihitemo ukoresheje Igenamiterere → MyTime Import. Komeza dosiye y'umwimerere uko iri. Niba backup nziza ikomeje kunanirwa, ohereza imeri ku bufasha mu ibanga ushyiremo ikosa na verisiyo ya porogaramu; ntushyire backup mu kibazo gishyirwa ahagaragara.
