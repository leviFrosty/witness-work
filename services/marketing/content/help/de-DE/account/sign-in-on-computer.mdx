---
id: signInOnComputer
title: Wie melde ich mich mit meinem Smartphone auf einem Computer an?
---

Zeigen Sie im Browser einen QR-Code und geben Sie ihn von Ihrem Smartphone aus frei. Sie brauchen WitnessWork auf einem iPhone oder Android-Smartphone, das bei Ihrem Konto angemeldet ist, und das Internet auf beiden Geräten.

## Auf einem Computer anmelden

1. Öffnen Sie auf dem Computer app.witnesswork.app und wählen Sie **Mein Smartphone verwenden**. Ein QR-Code erscheint.
2. Öffnen Sie auf Ihrem Smartphone **Einstellungen → Konto → Auf einem Computer anmelden**.
3. Scannen Sie den Code in WitnessWork. Ihre Kamera-App öffnet ihn nicht.
4. Prüfen Sie, ob der sechsstellige Code auf Ihrem Smartphone mit dem im Browser übereinstimmt.
5. Tippen Sie auf **Erlauben** und bestätigen Sie dann mit Face ID, Ihrem Fingerabdruck oder Ihrem Code.

Ihr Smartphone zeigt **Freigegeben**. Der Browser meldet sich an und bietet an, einen Passkey hinzuzufügen, damit Sie beim nächsten Mal das Smartphone überspringen können.

## Gut zu wissen

- Geben Sie nur einen Computer frei, der vor Ihnen steht. Wenn das Smartphone warnt, der Browser scheine weit weg zu sein, fahren Sie nur fort, wenn es Ihr eigener Computer ist.
- Wenn Sie das nicht gestartet haben, tippen Sie auf **Nicht erlauben**.
- Nur ein Smartphone kann einen Browser freigeben. Ohne Ihr Smartphone nutzen Sie einen Passkey oder Ihren Wiederherstellungsschlüssel. Siehe [Was ist, wenn ich den Zugang zu meinem WitnessWork-Konto verliere?](/help/account/lost-access).
- Ein Browser zeigt, dass er von einem Smartphone freigegeben wurde, das nicht Ihres ist: Wählen Sie **Das war ich nicht**. Siehe [Was tue ich, wenn mein Smartphone oder Computer verloren geht oder gestohlen wird?](/help/account/lost-device).

## Wenn etwas schiefgeht

- **Das Smartphone kann nicht scannen:** Erlauben Sie in den Einstellungen Ihres Smartphones, dass WitnessWork die Kamera nutzt.
- **Der Code ist nicht von WitnessWork oder gilt für ein anderes Smartphone:** Öffnen Sie auf dem Computer app.witnesswork.app und wählen Sie erneut **Mein Smartphone verwenden**.
- **Der Code ist abgelaufen:** Codes ändern sich etwa jede Minute und funktionieren einmal. Wählen Sie im Browser **Neuen Code anzeigen**.
- **Das Smartphone sagt, es könne dieses Gerät nicht verifizieren:** Dann kann es keinen Computer freigeben. Nutzen Sie stattdessen einen Passkey oder Ihren Wiederherstellungsschlüssel.
