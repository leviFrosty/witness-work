title: Hoe meld ik me op een computer aan met mijn telefoon?
---

Toon een QR-code in de browser en keur hem goed vanaf je telefoon. Je hebt WitnessWork nodig op een iPhone of Android-telefoon die bij je account is aangemeld, en internet op beide apparaten.

## Aanmelden op een computer

1. Open op de computer app.witnesswork.app en kies **Mijn telefoon gebruiken**. Er verschijnt een QR-code.
2. Open op je telefoon **Instellingen → Account → Aanmelden op een computer**.
3. Scan de code in WitnessWork. Je camera-app opent hem niet.
4. Controleer of de zescijferige code op je telefoon overeenkomt met die in de browser.
5. Tik op **Toestaan** en bevestig met Face ID, je vingerafdruk of je toegangscode.

Je telefoon toont **Goedgekeurd**. De browser meldt je aan en biedt aan een passkey toe te voegen, zodat je de volgende keer de telefoon kunt overslaan.

## Goed om te weten

- Keur alleen een computer goed die voor je staat. Waarschuwt de telefoon dat de browser ver weg lijkt, ga dan alleen verder als het je eigen computer is.
- Heb je dit niet zelf gestart, tik dan op **Niet toestaan**.
- Alleen een telefoon kan een browser goedkeuren. Zonder je telefoon gebruik je een passkey of je herstelsleutel. Zie [Wat als ik geen toegang meer heb tot mijn WitnessWork-account?](/help/account/lost-access).
- Toont een browser dat hij is goedgekeurd door een telefoon die niet van jou is, kies dan **Dat was ik niet**. Zie [Wat moet ik doen als mijn telefoon of computer is verloren of gestolen?](/help/account/lost-device).

## Als er iets misgaat

- **De telefoon kan niet scannen:** sta in de instellingen van je telefoon toe dat WitnessWork de camera gebruikt.
- **De code is niet van WitnessWork, of is voor een andere telefoon:** open op de computer app.witnesswork.app en kies opnieuw **Mijn telefoon gebruiken**.
- **De code is verlopen:** codes veranderen ongeveer elke minuut en werken één keer. Kies **Nieuwe code tonen** in de browser.
- **De telefoon zegt dat hij dit apparaat niet kan verifiëren:** hij kan geen computer goedkeuren. Gebruik in plaats daarvan een passkey of je herstelsleutel.
