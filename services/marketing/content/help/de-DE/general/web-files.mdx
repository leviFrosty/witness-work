title: Wie funktionieren Fotos, Exporte und Sicherungen im Web?
---

Im Web landen Downloads im Download-Ordner Ihres Browsers. Fotos in Notizen funktionieren, Profil- und Kontaktfotos noch nicht.

## Fotos

- **Fotos in Notizen:** Fügen Sie eines mit der Fototaste des Notizeditors hinzu, indem Sie ein kopiertes Bild einfügen oder eine Bilddatei auf die Notiz ziehen. Sie werden über Cloud Sync mit Ihren Smartphones abgeglichen. Die Notizfotos Ihrer Smartphones erscheinen, sobald sie heruntergeladen sind. Bis dahin steht in der Notiz „Dieses Foto ist nicht auf diesem Gerät.“
- Ihr Browser behält von jedem Foto eine eigene Kopie, und das Abmelden entfernt sie. Wenn dem Browser der Platz dafür ausgeht, sagt WitnessWork es Ihnen.
- **Profil- und Kontaktfotos:** Sie lassen sich im Web noch nicht hinzufügen, und die Fotos Ihrer Smartphones werden dort nicht angezeigt. Kontakte zeigen ihre Initialen.
- Wenn Sie einen Kontakt im Web bearbeiten, bleibt sein Foto auf Ihren Smartphones unberührt. Wenn Sie das Foto eines Kontakts oder Ihr Profilfoto im Web entfernen oder ersetzen, wird es dagegen auch von Ihren Smartphones entfernt.

## Downloads und Teilen

- **Ein Backup erstellen**, **CSV exportieren** für einen Bericht zur Fahrstrecke und andere Exporte werden als Dateien heruntergeladen. Ihr Browser fragt vielleicht, wo er sie speichern soll, oder listet sie in seinen Downloads auf.
- Auf einem Computer kopieren **Bericht teilen** und andere Textfreigaben den Text. Sie sehen „Kopiert!“ und können ihn dort einfügen, wo Sie ihn brauchen.
- Auf einem Smartphone öffnet das Teilen das Teilen-Menü des Smartphones. Wenn Ihr Browser das nicht kann, wird die Datei heruntergeladen.

## Importe

**Von der Sicherung wiederherstellen**, **Kontakt importieren** und der MyTime-Import öffnen die Dateiauswahl Ihres Browsers. MyTime-Dateien (.mytimedb) bleiben auf Ihrem Computer, und eine über 25 MB wird abgelehnt. WitnessWork-Sicherungen sind mit einem Passwort gesperrt. Geben Sie es zum Wiederherstellen ein.

## Gut zu wissen

- Eine heruntergeladene Sicherung kann Angaben zu Wohnungsinhabern enthalten. Halten Sie sie privat.

## Wenn etwas schiefgeht

- **Nichts wird heruntergeladen:** Prüfen Sie, ob Ihr Browser Downloads für diese Seite blockiert. Weitere Hilfe finden Sie unter [Support kontaktieren](/help).
