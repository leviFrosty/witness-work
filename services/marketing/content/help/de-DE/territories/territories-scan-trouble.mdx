---
id: territoriesScanTrouble
title: Warum kann ich den QR-Code der Karte nicht scannen, oder warum funktioniert mein Kartenlink nicht?
---

Sehen Sie sich die Meldung an, die Sie unten sehen. Wenn sich der Code der Karte nicht scannen lässt, können Sie stattdessen den Link eingeben oder eine andere Kartenoption nutzen.

## Den QR-Code der Karte scannen

Das gibt es nur in den Smartphone-Apps. Im Web fügen Sie den Link mit **Kartenlink eingeben** ein.

- **„WitnessWork braucht die Kamera, um einen QR-Code zu scannen.“** Tippen Sie auf **Einstellungen öffnen**, erlauben Sie die Kamera für WitnessWork und versuchen Sie es erneut.
- **„Dieser QR-Code enthält keinen Weblink.“** Der Code enthält etwas anderes als eine Webadresse. Nutzen Sie **Markierung auf einer Karte** oder **Gebiet umranden** oder fotografieren Sie die Karte.
- **Nichts passiert:** Halten Sie die Karte flach und ruhig bei gutem Licht, mit dem ganzen Code im Bild. Tippen Sie auf **Scannen beenden**, um stattdessen den Link einzugeben.

## Ein Kartenlink, der nicht funktioniert

**Kartenlink eingeben** speichert jeden Link, den Sie einfügen. Öffnen Sie ihn über die Taste **Karte** des Gebiets.

WitnessWork versucht außerdem, die Stelle für **Wegbeschreibung** zu markieren. Das funktioniert bei Links zu einem Ort in Google Maps, Apple Karten oder OpenStreetMap. Ein Kurzlink, zum Beispiel maps.app.goo.gl, braucht eine Verbindung, solange „Standort wird gesucht…“ angezeigt wird.

Wenn keine Markierung erscheint, öffnet sich der Link trotzdem. Tippen Sie auf **Markierung auf einer Karte** und tippen Sie dorthin, wo das Gebiet ist. Eine Markierung, die Sie selbst gesetzt haben, wird von einem Link nicht verschoben.

## Notizen scannen

Auf iPhone und iPad bedeutet „Im Scan wurde keine Schrift gefunden“, dass Sie bei besserem Licht und flach liegender Seite noch einmal scannen oder die Notizen tippen sollten. Auf Android kopieren Sie den Text aus einem Foto mit Google Lens und fügen ihn dann ein.
