title: Comment modifier ou supprimer du temps déjà enregistré ?
---

Ouvrez **Ajouter du temps**, choisissez le jour et touchez l’entrée que vous voulez modifier ou supprimer.

## Modifier une entrée

1. Sur l’**Accueil**, ouvrez **Ajouter du temps**. Vous pouvez aussi utiliser le bouton **+**.
2. Touchez le jour dans la rangée de jours en haut. Pour choisir un autre jour, touchez la date au-dessus.
3. Touchez l’entrée dans la liste sous les jours.
4. Modifiez le temps, le Type ou la note. Pour la déplacer, touchez un autre jour.
5. Touchez **Enregistrer**.

Pour quitter une entrée sans enregistrer, touchez-la de nouveau. Si vous avez modifié quelque chose, WitnessWork vous demande avant d’abandonner la modification.

## Supprimer une entrée

1. Ouvrez **Ajouter du temps** et choisissez le jour.
2. Gardez le doigt appuyé sur l’entrée, puis choisissez **Supprimer**. Sur le web, faites un clic droit dessus.

Une suppression ne peut pas être annulée.

## Bon à savoir

- Un jour qui a plus de trois entrées montre les deux premières. Touchez **Afficher plus** pour voir le reste.
- Pour enregistrer du temps sur plusieurs jours, ajoutez la première entrée, puis touchez **Ajouter une autre** dans le message qui la confirme.
- L’enregistrement du temps n’apparaît que si votre statut enregistre des heures. Les proclamateurs du Royaume activent d’abord **Enregistrer mes heures** dans **Paramètres → Profil**.
- Vous pouvez aussi modifier une entrée depuis son jour. Voir [Comment enregistrer du temps ou planifier un jour précis ?](/help/time/log-time-for-day)
