---
id: webApp
title: Puis-je utiliser WitnessWork dans un navigateur web ?
---

Oui. Ouvrez [app.witnesswork.app](https://app.witnesswork.app) dans un navigateur récent, sur un ordinateur, un téléphone ou une tablette. C’est l’application WitnessWork complète, avec le même compte que vos téléphones : votre temps, vos plans, vos contacts, vos notes et vos Compagnons sont là dès que vous vous connectez.

## Se connecter

Choisissez l’une de ces options sur l’écran de connexion :

1. Une clé d’accès.
2. Votre téléphone. Voir [se connecter sur un ordinateur avec votre téléphone](/help/account/sign-in-on-computer).
3. Votre clé de récupération.

Pour repartir de zéro, choisissez **Créer un compte**. Voir [Puis-je créer un compte sur le web ?](/help/account/web-sign-up).

Après votre connexion, WitnessWork récupère d’abord vos enregistrements. Votre travail est enregistré dans votre navigateur, se synchronise par Cloud Sync et continue de fonctionner hors ligne. Voir [hors ligne sur le web](/help/general/web-offline). Pour l’ouvrir comme une application, voir [l’installer](/help/general/web-install).

## Ce que l’application web n’a pas

- Les notifications et les rappels sur l’appareil. Les plans et les suivis que vous créez sur le web vous rappellent sur vos téléphones. La cloche sur l’Accueil fonctionne sur le web.
- Les widgets, les Live Activities, Siri et Raccourcis, les applications de montre et les icônes d’application alternatives.
- La synchronisation iCloud et la synchronisation Google Drive. Le web n’utilise que Cloud Sync. Si vos téléphones utilisent autre chose, le web vous demande d’abord d’activer [Cloud Sync](/help/backups/cloud-sync).
- La synchronisation du calendrier.
- La saisie vocale et par photo dans Scribe AI. Vous lui écrivez à la place.
- Les photos de profil et de contacts. Les contacts affichent leurs initiales. Les photos dans les notes fonctionnent. Voir [fichiers et photos sur le web](/help/general/web-files).

## Bon à savoir

- La carte fonctionne, et les exports et les sauvegardes se téléchargent sous forme de fichiers.
- L’application web vient du site de WitnessWork à chaque ouverture. Si vous préférez ne pas utiliser de navigateur, WitnessWork fonctionne entièrement sur votre téléphone seul.

## En cas de problème

- **Impossible de préparer votre compte :** vérifiez votre connexion et choisissez **Réessayer**, ou déconnectez-vous.
- **Il indique que Cloud Sync est en pause, ou qu’un appareil a enregistré des données que le navigateur ne peut pas encore lire :** vos données sont en sécurité. Rechargez la page plus tard, puis choisissez **Réessayer**.
