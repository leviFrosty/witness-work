title: Wat als aanmelden met een QR-code niet werkt?
---

Maak op je oude telefoon een nieuwe code en scan die opnieuw. Elke code werkt één keer en blijft 10 minuten geldig.

## Probeer dit

1. Tik op de oude telefoon op **Nieuwe code maken**.
2. Controleer of beide telefoons online zijn.
3. Scan de nieuwe code met de nieuwe telefoon.
4. Controleer of beide telefoons dezelfde zescijferige code tonen en tik dan op de oude telefoon op **Toestaan**.

## Als er iets misgaat

- **De codes komen niet overeen:** tik op **Niet toestaan** en begin opnieuw. Misschien heeft iemand anders je code gescand.
- **De verbinding viel weg nadat je op Toestaan tikte:** houd beide telefoons op het scherm. De nieuwe telefoon toont **Probeer opnieuw** en gaat vanzelf verder zodra hij weer online is.
- **De oude telefoon zegt dat je account niet is verstuurd:** controleer de verbinding en tik opnieuw op **Toestaan**.
- **De nieuwe telefoon kan niet scannen:** sta in de instellingen van je telefoon toe dat WitnessWork de camera gebruikt.
- **De nieuwe telefoon kan zichzelf niet verifiëren:** installeer WitnessWork uit de App Store of Google Play. Zie [Waarom zegt WitnessWork dat dit apparaat niet kan worden geverifieerd?](/help/account/account-verification).
- **Je hebt je oude telefoon niet meer:** ga op de nieuwe telefoon naar **Instellingen → Account → Een herstelsleutel gebruiken**. Zie [Wat als ik geen toegang meer heb tot mijn WitnessWork-account?](/help/account/lost-access).

Kom je er nog niet uit? Neem contact op met support via het Helpcentrum. Stuur je herstelsleutel nooit naar iemand.
