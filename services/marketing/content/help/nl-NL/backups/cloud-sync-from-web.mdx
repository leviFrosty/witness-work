---
id: cloudSyncFromWeb
title: Waarom is mijn telefoon overgestapt op Cloud Sync nadat ik me op het web aanmeldde?
---

Als je je op het web aanmeldt, wordt gevraagd [Cloud Sync](/help/backups/cloud-sync) aan te zetten, omdat het web alleen met Cloud Sync werkt. Als je **Aanzetten** kiest, stapt je telefoon over op Cloud Sync zodra je WitnessWork er de volgende keer opent.

## Er gaat niets verloren

- Je telefoon houdt alle gegevens en foto's en voegt ze samen met wat al in Cloud Sync staat.
- Wat je hebt verwijderd komt niet terug.
- Je andere telefoons met hetzelfde account stappen ook over, elk zodra je WitnessWork erop opent.
- Je gegevens zijn privé. Alleen je eigen apparaten kunnen ze lezen.

## Terugschakelen

1. Open op je telefoon **Instellingen → Synchroniseer**.
2. Kies iCloud (Google Drive op Android) of Uit.

Je telefoon blijft op de optie die je kiest. Het web vraagt het opnieuw als je het de volgende keer gebruikt.

## Als het niet overstapt

- Zorg dat je telefoon online is en je klaar bent met het instellen van WitnessWork, en open de app daarna opnieuw.
- Staat er op het web **Werk WitnessWork bij op je telefoon**? Werk dan de app bij via de App Store of Google Play en open hem.
- Je kunt Cloud Sync altijd zelf kiezen in **Instellingen → Synchroniseer**.
